Aprende › Patrones gramaticales del coreano › Nivel 2

-(으)ㄴ

modificador del sustantivo para una acción pasada (verbos): el N que alguien hizo

Nivel 2, TOPIK I · principiante

Cómo se usa

Se une a la raíz de un verbo para describir un sustantivo con una acción terminada: 어제 본 영화 'la película que vi ayer'. Las raíces en vocal toman -ㄴ (la ㄹ se cae: 만들다 → 만든); las raíces en consonante toman -은.

Cómo se forma

가다→ 간
먹다→ 먹은
만들다→ 만든
듣다→ 들은

Con adjetivos, -(으)ㄴ es presente, no pasado: 예쁜 꽃 = una flor bonita. Para el presente de un verbo usa -는: ✗ 지금 먹은 사람 (queriendo decir 'que está comiendo ahora') → 지금 먹는 사람.

Ejemplos

  • 어제 본 영화가 정말 재미있었어요.

    La película que vi ayer estuvo muy buena.

  • 제가 만든 김치예요. 한번 드셔 보세요.

    Este es un kimchi que hice yo. Pruébalo.

Comparado con patrones parecidos

-는 = acción que ocurre ahora o habitualmente; -(으)ㄹ = futuro o aún no realizado; -았/었던 evoca un hecho pasado que ya terminó o ya no es cierto.

Patrones relacionados

  • -(으)ㄴ/는 modificador del sustantivo, presente (A-(으)ㄴ, V-는)
  • -(으)ㄹ modificador del sustantivo para futuro / algo aún no hecho: el N por hacer, el N que haré
  • -았/었던 que (una vez) hizo / era: pasado terminado, a menudo ya no vigente
