Patrones gramaticales del coreano › Nivel 2

-(으)ㄴ/는/(으)ㄹ 것 같다

parecer, verse; creo que (suposición u opinión suave)

Nivel 2 · TOPIK I · principiante

Cómo se usa

Expresa una suposición basada en lo que ves o sabes, o suaviza tu opinión. El modificador indica el tiempo: verbos -(으)ㄴ (pasado), -는 (presente), -(으)ㄹ (futuro/suposición); adjetivos -(으)ㄴ (presente), -(으)ㄹ (suposición).

Cómo se forma

오다→ 온 것 같아요
오다→ 오는 것 같아요
오다→ 올 것 같아요
바쁘다→ 바쁜 것 같아요

Los adjetivos nunca toman -는: ✗ 바쁘는 것 같아요 → 바쁜 것 같아요. Irregular en ㅂ: 춥다 → 추울 것 같아요.

Ejemplos

  • 하늘이 어두워요. 곧 비가 올 것 같아요.

    El cielo está oscuro. Creo que pronto va a llover.

  • 선생님이 오늘 좀 피곤하신 것 같아요.

    Parece que el profesor está un poco cansado hoy.

Comparado con patrones parecidos

-나 보다 es una inferencia a partir de indicios y no se usa para tu propia experiencia u opinión; -(으)ㄴ/는 모양이다 es una inferencia más distante a partir de señales; -(으)ㄴ/는 듯하다 es su equivalente escrito.

Patrones relacionados

  • -나 보다 parece que, supongo que (inferencia por lo que se ve)
  • -(으)ㄴ/는 모양이다 parece que, por lo visto (inferencia a partir de indicios)
  • -(으)ㄴ/는 듯하다 parecer (más suave y escrito que -(으)ㄴ/는 것 같다)
