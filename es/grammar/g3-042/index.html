-아/어 달라고 하다

pedir (a alguien) que haga algo por uno (petición indirecta)

Nivel 3 · TOPIK II · intermedio

Cómo se usa

Cita indirecta de una petición '-아/어 주세요'. Cuando quien pide es el beneficiado, usa 달라고; cuando el beneficio es para una tercera persona, usa 주라고.

Cómo se forma

돕다→ 도와 달라고 하다
사다→ 사 달라고 하다
기다리다→ 기다려 달라고 하다
보내다→ 보내 달라고 하다

✗ 동생이 저한테 숙제를 도와 주라고 했어요 (cuando el hermano quiere ayuda para sí mismo) → 도와 달라고 했어요.

Ejemplos

  • 친구가 숙제를 좀 도와 달라고 했어요.

    Mi amigo me pidió que lo ayudara con su tarea.

  • 아이가 장난감을 사 달라고 계속 졸라요.

    El niño no deja de rogar que le compren un juguete.

Comparado con patrones parecidos

-(으)라고 하다 cita una orden simple; -아/어 달라고 하다 cita la petición de un favor. -아/어 주다 es la base 'hacer algo por alguien'.
