Patrones gramaticales del coreano › Nivel 3

-(으)ㄹ 겸

también para…; con el doble propósito de…

Nivel 3 · TOPIK II · intermedio

Cómo se usa

Indica que una acción sirve para dos o más propósitos. A menudo con 도: A도 할 겸 B도 할 겸. N 겸 N = N y N a la vez (아침 겸 점심 = brunch).

Cómo se forma

쉬다→ 쉴 겸
먹다→ 먹을 겸
운동하다→ 운동할 겸
아침→ 아침 겸 점심

Ejemplos

  • 운동도 할 겸 걸어서 출근해요.

    Voy caminando al trabajo, en parte para hacer ejercicio.

  • 친구도 만날 겸 쇼핑도 할 겸 시내에 나갔어요.

    Fui al centro para ver a un amigo y de paso hacer compras.

Comparado con patrones parecidos

-(으)ㄴ/는 김에 aprovecha una ocasión para hacer algo extra no planeado. -(으)려고 da un solo propósito.
