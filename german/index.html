자주 묻는 질문

평생 이용권은 어떤 건가요?

한 번만 결제하면 모든 레벨과 기능을 계속 쓸 수 있어요. 구독이 아니라서 매달 결제되거나 해지할 필요가 없어요.

새 폰이나 앱을 다시 설치했을 때 평생 이용권은?

구매할 때 쓴 Apple ID로 App Store에 로그인한 뒤 앱에서 평생 이용권 구매를 다시 눌러 주세요. Apple이 이미 구매한 항목이라고 알려 주고, 추가 결제 없이 다시 열려요.

환불받고 싶어요.

환불은 저희가 아니라 Apple이 처리해요. reportaproblem.apple.com에서 요청해 주세요.

소리가 안 나요.

볼륨, 블루투스 이어폰 연결, 인터넷 연결을 확인해 주세요. 그래도 안 되면 앱을 완전히 닫았다가 다시 열어 주세요.

폰을 바꿨더니 학습 기록이 없어졌어요.

학습 기록은 기기에만 저장되고 서버에 따로 보관하지 않아요. 그래서 다른 기기로 옮길 수 없어요.

웹에서는 어디까지 무료인가요?

A1 단어와 주제별 단어는 웹 앱에서 무료로 써 볼 수 있어요. 그 이상은 앱에서 평생 이용권으로 열려요.

수집하지 않는 정보

  • 회원가입이나 로그인이 필요 없어요.
  • 이름, 이메일 주소, 연락처, 위치, 기기 식별자를 수집하지 않아요.
  • 광고, 광고 식별자(IDFA 등), 분석 도구(SDK), 추적 쿠키를 쓰지 않아요.
  • 개인정보를 판매하거나 제3자에게 제공하지 않아요.

기기에 저장되는 정보

학습 진도, 북마크, 퀴즈 기록, 설정은 사용자의 기기(브라우저 저장소 또는 앱 저장소)에만 저장돼요. 내려받은 발음 음성 파일도 기기에 저장돼요. 저희는 이 정보를 볼 수 없어요. 사이트·앱 데이터를 지우거나 앱을 삭제하면 언제든 모두 지워져요.

앱 내 구매

평생 이용권(한 번 결제) 구매는 전부 Apple(App Store)이 처리해요. 저희는 결제 정보를 받지 않아요. 앱은 기기에서 프리미엄을 열어 주기 위해 스토어에 구매가 유효한지만 확인해요. 구독 상품은 없어요.

발음 음성

음성은 대부분 미리 녹음된 파일이에요. 웹사이트의 일부 단어와 문장은 읽어 줄 텍스트(예: 독일어 문장)를 저희 서버에서 Google Cloud Text-to-Speech로 보내 음성을 만들어요. 이때 보내는 것은 읽을 텍스트뿐이고, 사용자에 관한 정보는 보내지 않아요.

호스팅과 서버 기록

웹사이트, 웹 앱, 음성 파일은 Cloudflare, Inc.를 통해 제공돼요. 페이지나 음성 파일을 불러올 때 Cloudflare가 콘텐츠 전송과 악용 방지를 위해 IP 주소, 브라우저 종류 같은 기술 정보를 처리해요. 저희는 이 정보로 사용자를 식별하지 않고 다른 정보와 결합하지도 않아요.
