韓文文法句型 › 第 2 級

-(으)ㄴ/는/(으)ㄹ 것 같다

好似、睇嚟；我覺得（推測或者婉轉意見）

第 2 級 · TOPIK I · 初級

點樣用

根據見到或者知道嘅嘢推測，或者令自己嘅意見講得婉轉啲。冠形詞形表示時間：動詞 -(으)ㄴ（過去）、-는（現在）、-(으)ㄹ（將來／推測）；形容詞 -(으)ㄴ（現在）、-(으)ㄹ（推測）。

點樣變

오다→ 온 것 같아요
오다→ 오는 것 같아요
오다→ 올 것 같아요
바쁘다→ 바쁜 것 같아요

形容詞永遠唔加 -는：✗ 바쁘는 것 같아요 → 바쁜 것 같아요。ㅂ不規則：춥다 → 추울 것 같아요。

例句

  • 하늘이 어두워요. 곧 비가 올 것 같아요.

    個天好黑，好似就快落雨。

  • 선생님이 오늘 좀 피곤하신 것 같아요.

    老師今日好似有啲攰。

同相似句型比較

-나 보다 係根據證據推斷，唔用喺自己嘅經驗或者意見；-(으)ㄴ/는 모양이다 係根據跡象、較抽離嘅推斷；-(으)ㄴ/는 듯하다 係書面講法。
