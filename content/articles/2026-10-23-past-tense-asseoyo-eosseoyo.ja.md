「週末は何をしましたか？」は、韓国の月曜日にいちばんよく聞かれる質問かもしれません。これに答えるには過去形が必要です。うれしいことに、過去形はすでに知っているかもしれない現在形の語尾**-아요/어요**をもとに作ります。**요**を**ㅆ어요**に替えれば過去形です。**가요**（gayo）＝行きます、が**갔어요**（gasseoyo）＝行きました、になります。

## 基本のルール

動詞の語幹（辞書形から**-다**を取ったもの）の最後の母音を見ます。

- 最後の母音が**ㅏかㅗ** → **-았어요**（-asseoyo）をつける
- それ以外の母音 → **-었어요**（-eosseoyo）をつける
- **하다**で終わるもの → **했어요**（haesseoyo）

現在形とまったく同じ母音の選び方なので、**먹어요**が言えれば**먹었어요**も言えます。

| 辞書形 | 語幹 | 過去形（丁寧） | 意味 |
|---|---|---|---|
| [살다](/ja/dictionary/?q=살다) (salda) | 살- | 살았어요 (sarasseoyo) | 住んでいました |
| 좋다 (jota) | 좋- | 좋았어요 (joasseoyo) | よかったです |
| [먹다](/ja/dictionary/?q=먹다) (meokta [먹따]) | 먹- | 먹었어요 (meogeosseoyo) | 食べました |
| 읽다 (ikta [익따]) | 읽- | 읽었어요 (ilgeosseoyo) | 読みました |
| 맛있다 (masitta [마싣따]) | 맛있- | 맛있었어요 (masisseosseoyo) | おいしかったです |
| [공부하다](/ja/dictionary/?q=공부하다) (gongbuhada) | 공부하- | 공부했어요 (gongbuhaesseoyo) | 勉強しました |
| 일하다 (ilhada) | 일하- | 일했어요 (ilhaesseoyo) | 働きました |

## 母音が合体するもの

語幹が母音で終わるときは、現在形と同じように、2つの母音がたいてい合わさって1つになります。

| 辞書形 | 過去形（丁寧） | 変化のしかた |
|---|---|---|
| [가다](/ja/dictionary/?q=가다) (gada) | 갔어요 (gasseoyo) | 가 + 았 → 갔 |
| 오다 (oda) | 왔어요 (wasseoyo) | 오 + 았 → 왔 |
| [보다](/ja/dictionary/?q=보다) (boda) | 봤어요 (bwasseoyo) | 보 + 았 → 봤 |
| 마시다 (masida) | 마셨어요 (masyeosseoyo) | 시 + 었 → 셨 |
| 배우다 (baeuda) | 배웠어요 (baewosseoyo) | 우 + 었 → 웠 |
| 서다 (seoda) | 섰어요 (seosseoyo) | 서 + 었 → 섰 |
| 보내다 (bonaeda) | 보냈어요 (bonaesseoyo) | 내 + 었 → 냈 |

**쉬다**（swida）＝休む、のように合体しない語幹もあります：**쉬었어요**（swieosseoyo）。

## 名詞：이었어요／였어요

名詞で「〜でした」と言うときは、子音（パッチム）の後では**이었어요**、母音の後では**였어요**を使います。

- **어제는 제 생일이었어요.**（Eojeneun je saengirieosseoyo.）＝昨日はわたしの誕生日でした。
- **그 사람은 제 친구였어요.**（Geu sarameun je chinguyeosseoyo.）＝その人はわたしの友だちでした。

## 不規則動詞はクセをそのまま残す

不規則動詞は、過去形でも現在形とまったく同じように変化するので、ペアで覚えましょう。

- **듣다**（deutta [듣따]）＝聞く → 들었어요（deureosseoyo）
- **춥다**（chupta [춥따]）＝寒い → 추웠어요（chuwosseoyo）
- **바쁘다**（bappeuda）＝忙しい → 바빴어요（bappasseoyo）
- **쓰다**（sseuda）＝書く、使う → 썼어요（sseosseoyo）
- **모르다**（moreuda）＝知らない → 몰랐어요（mollasseoyo）

## 過去の否定

過去形の動詞の前に**안**（〜しない）や**못**（〜できない）を置きます。

- **아침을 안 먹었어요.**（Achimeul an meogeosseoyo.）＝朝ごはんを食べませんでした。
- **어제 못 잤어요.**（Eoje mot jasseoyo.）＝昨夜は眠れませんでした。

**하다**動詞では、否定は**했어요**のすぐ前に入ります：**공부 안 했어요**（gongbu an haesseoyo）＝勉強しませんでした。

## 一緒に使う時間の言葉

**어제**（eoje）＝昨日、**지난주**（jinanju）＝先週、**주말에**（jumare）＝週末に、**작년**（jangnyeon）＝去年。10月下旬は練習にぴったりの時期です：**주말에 단풍 구경 갔어요.**（Jumare danpung gugyeong gasseoyo.）＝週末に紅葉を見に行きました。

友だちとのくだけた会話では、**요**を取るだけです：**갔어**、**먹었어**、**뭐 했어?**

## ミニ練習

次を丁寧な過去形にしてみましょう。答えは下にあります。

1. 만나다（会う）
2. 마시다（飲む）
3. 청소하다（掃除する）
4. 덥다（暑い）
5. 학생（学生）＋でした

**答え：** 1. 만났어요 (mannasseoyo) 2. 마셨어요 (masyeosseoyo) 3. 청소했어요 (cheongsohaesseoyo) 4. 더웠어요 (deowosseoyo) 5. 학생이었어요 (hakssaengieosseoyo [학쌩이어써요])

## 使える韓国語

| 韓国語 | ローマ字 | 意味 |
|---|---|---|
| 주말에 뭐 했어요? | jumare mwo haesseoyo? | 週末は何をしましたか？ |
| 친구를 만났어요 | chingureul mannasseoyo | 友だちに会いました |
| 영화를 봤어요 | yeonghwareul bwasseoyo | 映画を見ました |
| 집에서 쉬었어요 | jibeseo swieosseoyo | 家で休みました |
| 정말 재미있었어요 | jeongmal jaemiisseosseoyo | 本当に楽しかったです |
| 너무 바빴어요 | neomu bappasseoyo | とても忙しかったです |
| 몰랐어요 | mollasseoyo | 知りませんでした |
