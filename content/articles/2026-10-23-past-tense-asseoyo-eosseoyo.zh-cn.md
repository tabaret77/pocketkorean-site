“周末你做了什么？”大概是在韩国的周一最常听到的问题。要回答它，你需要用过去式。好消息是，过去式是在你可能已经学过的现在时词尾**-아요/어요**的基础上构成的。把**요**换成**ㅆ어요**，就变成过去式了。**가요**（gayo）——我去——变成**갔어요**（gasseoyo）——我去了。

## 基本规则

取动词词干（词典形去掉**-다**），看它的最后一个元音：

- 最后一个元音是**ㅏ或ㅗ** → 加**-았어요**（-asseoyo）
- 其他任何元音 → 加**-었어요**（-eosseoyo）
- 以**하다**结尾的 → **했어요**（haesseoyo）

这和现在时的元音选择完全一样，所以如果你会说**먹어요**，就会说**먹었어요**。

| 词典形 | 词干 | 过去式（礼貌体） | 意思 |
|---|---|---|---|
| [살다](/zh-cn/dictionary/?q=살다) (salda) | 살- | 살았어요 (sarasseoyo) | 我住过，我生活过 |
| 좋다 (jota) | 좋- | 좋았어요 (joasseoyo) | （当时）很好 |
| [먹다](/zh-cn/dictionary/?q=먹다) (meokta [먹따]) | 먹- | 먹었어요 (meogeosseoyo) | 我吃了 |
| 읽다 (ikta [익따]) | 읽- | 읽었어요 (ilgeosseoyo) | 我读了 |
| 맛있다 (masitta [마싣따]) | 맛있- | 맛있었어요 (masisseosseoyo) | （当时）很好吃 |
| [공부하다](/zh-cn/dictionary/?q=공부하다) (gongbuhada) | 공부하- | 공부했어요 (gongbuhaesseoyo) | 我学习了 |
| 일하다 (ilhada) | 일하- | 일했어요 (ilhaesseoyo) | 我工作了 |

## 会合并的元音

词干以元音结尾时，两个元音通常会缩合在一起，和现在时一样：

| 词典形 | 过去式（礼貌体） | 变化过程 |
|---|---|---|
| [가다](/zh-cn/dictionary/?q=가다) (gada) | 갔어요 (gasseoyo) | 가 + 았 → 갔 |
| 오다 (oda) | 왔어요 (wasseoyo) | 오 + 았 → 왔 |
| [보다](/zh-cn/dictionary/?q=보다) (boda) | 봤어요 (bwasseoyo) | 보 + 았 → 봤 |
| 마시다 (masida) | 마셨어요 (masyeosseoyo) | 시 + 었 → 셨 |
| 배우다 (baeuda) | 배웠어요 (baewosseoyo) | 우 + 었 → 웠 |
| 서다 (seoda) | 섰어요 (seosseoyo) | 서 + 었 → 섰 |
| 보내다 (bonaeda) | 보냈어요 (bonaesseoyo) | 내 + 었 → 냈 |

有少数词干不会缩合，比如**쉬다**（swida）——休息：**쉬었어요**（swieosseoyo）。

## 名词：이었어요／였어요

要用名词说“曾经是……”，辅音后面用**이었어요**，元音后面用**였어요**：

- **어제는 제 생일이었어요.**（Eojeneun je saengirieosseoyo.）——昨天是我的生日。
- **그 사람은 제 친구였어요.**（Geu sarameun je chinguyeosseoyo.）——那个人曾是我的朋友。

## 不规则动词保持各自的特点

不规则动词在过去式里的变化方式和现在时完全一样，所以要成对地记：

- **듣다**（deutta [듣따]）——听 → 들었어요（deureosseoyo）
- **춥다**（chupta [춥따]）——冷 → 추웠어요（chuwosseoyo）
- **바쁘다**（bappeuda）——忙 → 바빴어요（bappasseoyo）
- **쓰다**（sseuda）——写，用 → 썼어요（sseosseoyo）
- **모르다**（moreuda）——不知道 → 몰랐어요（mollasseoyo）

## 过去式的否定

在过去式动词前面加上**안**（不）或**못**（没能）：

- **아침을 안 먹었어요.**（Achimeul an meogeosseoyo.）——我没吃早饭。
- **어제 못 잤어요.**（Eoje mot jasseoyo.）——我昨晚没睡着。

**하다**类动词的否定词直接放在**했어요**前面：**공부 안 했어요**（gongbu an haesseoyo）——我没学习。

## 常搭配的时间词

**어제**（eoje）——昨天，**지난주**（jinanju）——上周，**주말에**（jumare）——周末，**작년**（jangnyeon）——去年。10月下旬正是练习的好时机：**주말에 단풍 구경 갔어요.**（Jumare danpung gugyeong gasseoyo.）——周末我去看红叶了。

和朋友随意聊天时，去掉**요**就行：**갔어**，**먹었어**，**뭐 했어?**

## 小练习

把下面的词变成礼貌体过去式。答案在下面。

1. 만나다（见面）
2. 마시다（喝）
3. 청소하다（打扫）
4. 덥다（热）
5. 학생（学生）+ 曾经是

**答案：** 1. 만났어요 (mannasseoyo) 2. 마셨어요 (masyeosseoyo) 3. 청소했어요 (cheongsohaesseoyo) 4. 더웠어요 (deowosseoyo) 5. 학생이었어요 (hakssaengieosseoyo [학쌩이어써요])

## 可以直接用的韩语

| 韩语 | 罗马音 | 意思 |
|---|---|---|
| 주말에 뭐 했어요? | jumare mwo haesseoyo? | 周末你做了什么？ |
| 친구를 만났어요 | chingureul mannasseoyo | 我见了朋友 |
| 영화를 봤어요 | yeonghwareul bwasseoyo | 我看了电影 |
| 집에서 쉬었어요 | jibeseo swieosseoyo | 我在家休息了 |
| 정말 재미있었어요 | jeongmal jaemiisseosseoyo | 真的很有意思 |
| 너무 바빴어요 | neomu bappasseoyo | 我太忙了 |
| 몰랐어요 | mollasseoyo | 我（之前）不知道 |

**주말에 ___았어요/었어요.**（Jumare ___asseoyo/eosseoyo.）——周末我___了。下周一，用你自己的三句话来回答关于周末的问题吧。
