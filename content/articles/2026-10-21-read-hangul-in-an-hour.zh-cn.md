韩语乍一看像是一堵由小方块砌成的墙，但这些方块其实都是由一小套字母组成的。**[한글](/zh-cn/dictionary/?q=한글)**（hangeul）——韩文字母——从设计之初就是为了好学。它在世宗大王主持下创制，于1446年以**훈민정음**（Hunminjeongeum，训民正音）之名颁布，意思是“教百姓以正确的字音”。给它一个小时，你就能拼读招牌和菜单了。

## 14个基本辅音

有几个辅音的形状就是口腔的简笔画：**ㄱ**表示舌根抵住上腭，**ㄴ**表示舌尖抵住齿背，**ㅁ**表示闭合的双唇。再加笔画就表示送气：**ㄱ → ㅋ**，**ㄷ → ㅌ**，**ㅂ → ㅍ**，**ㅈ → ㅊ**。

| 字母 | 发音 | 字母 | 发音 |
|---|---|---|---|
| ㄱ | g / k | ㅇ | 在开头不发音，在末尾发ng |
| ㄴ | n | ㅈ | j |
| ㄷ | d / t | ㅊ | ch（类似拼音q） |
| ㄹ | r / l | ㅋ | k（送气） |
| ㅁ | m | ㅌ | t（送气） |
| ㅂ | b / p | ㅍ | p（送气） |
| ㅅ | s | ㅎ | h |

普通辅音ㄱ、ㄷ、ㅂ、ㅈ的发音和汉语拼音的g、d、b、j很接近，都是不送气音；而ㅋ、ㅌ、ㅍ、ㅊ则像拼音的k、t、p、q那样送气。在词首时，ㄱ、ㄷ、ㅂ、ㅈ听起来稍微更接近k、t、p、ch；夹在元音之间时则会变得柔和，接近g、d、b、j。这就是为什么**김치**（gimchi）——泡菜——在官方罗马音中写作g，但听起来却更像“kimchi”。

## 10个基本元音

元音由三个元素构成：一个点或短横（代表天）、一条横线**ㅡ**（代表地）和一条竖线**ㅣ**（代表人）。再加一个短横，就多出一个“y”音。

| 元音 | 发音 | 元音 | 发音 |
|---|---|---|---|
| ㅏ | a（像“啊”） | ㅗ | o（圆唇，像“哦”） |
| ㅑ | ya | ㅛ | yo |
| ㅓ | eo（嘴张开、不圆唇的“哦”） | ㅜ | u（像“乌”） |
| ㅕ | yeo | ㅠ | yu |
| ㅣ | i（像“衣”） | ㅡ | eu（嘴唇平展，像“资”zi的韵母） |

这就是24个字母。此外还有五个双辅音（ㄲ、ㄸ、ㅃ、ㅆ、ㅉ）和十一个复合元音，比如**ㅐ**（ae）、**ㅔ**（e）和**ㅘ**（wa），不过它们都是由基本字母组合而成的，以后学起来会很轻松。

## 拼成音节方块

韩语不像英语那样把字母排成一行，而是每个音节组成一个方块，有点像汉字一字一格。每个方块至少有一个辅音和一个元音，元音的形状决定它放在哪里。

**1. 竖长的元音（ㅏ ㅑ ㅓ ㅕ ㅣ）放在辅音右边。**

- ㄴ + ㅏ = **나**（na）
- ㅁ + ㅓ = **머**（meo）

**2. 扁平的元音（ㅗ ㅛ ㅜ ㅠ ㅡ）放在辅音下面。**

- ㄱ + ㅗ = **고**（go）
- ㄴ + ㅜ = **누**（nu）

**3. 以元音开头的音节，用不发音的ㅇ占位。**

- ㅇ + ㅏ = **아**（a）
- ㅇ + ㅜ = **우**（u）

元音不能单独构成一个方块，所以由ㅇ来填补空着的辅音位置。

**4. 末尾辅音放在最下面。**这个底部的辅音叫作**받침**（batchim），意思是“支撑”，中文常称“收音”。

- ㅎ + ㅏ + ㄴ = **한**（han）
- ㄱ + ㅜ + ㄱ = **국**（guk）
- 한 + 국 = **한국**（Hanguk）——韩国

在方块底部时，ㅇ读作“ng”：**강**（gang）——江，河。

## 练习读一读

遮住罗马音，试着读读下面这些词。它们只用到了24个基本字母：

| 韩语 | 罗马音 | 意思 |
|---|---|---|
| 나무 | namu | 树 |
| 바다 | bada | 大海 |
| 우유 | uyu | 牛奶 |
| 서울 | Seoul | 首尔 |
| 사랑 | sarang | 爱 |
| 친구 | chingu | 朋友 |
| 라면 | ramyeon | 方便面 |
| 한국어 | hangugeo | 韩语 |

注意在**한국어**里，국的末尾ㄱ会滑进下一个音节，因为어以不发音的ㅇ开头：所以读作“han-gu-geo”。只要末尾辅音遇到元音，韩语都会这样连读，让说话更加流畅。

## 第一个小时的小贴士

- **先学元音。**只有十个，而且它们是每个方块的骨架。
- **读真实的单词，而不只是字母。**商店招牌、地铁站名和K-pop歌名都是绝佳的练习材料。
- **亲手写每个方块。**笔顺一般是从上到下、从左到右。
- **不要长期依赖罗马音。**它就像一根拐杖，可能会掩盖真实的发音，尤其是ㅓ和ㅡ。

## 可以直接用的韩语

| 韩语 | 罗马音 | 意思 |
|---|---|---|
| 한글 | hangeul | 韩文字母 |
| 자음 | jaeum | 辅音 |
| 모음 | moeum | 元音 |
| 받침 | batchim | 收音（末尾辅音） |
| [읽다](/zh-cn/dictionary/?q=읽다) | ikda | 读 |
| 이거 어떻게 읽어요? | igeo eotteoke ilgeoyo? | 这个怎么读？ |

一旦掌握了方块的拼法，你遇到的每个韩语单词都能大声读出来，这才是学韩语真正的开始。
