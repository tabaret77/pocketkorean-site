韓国語の語尾をひとつだけ覚えるなら、**-아요/어요**（-ayo/-eoyo）にしましょう。お店のスタッフ、同僚、知り合ったばかりの人など、それほど親しくない大部分の人に対して韓国人が使う、親しみやすく丁寧なスタイルです。文法書では**해요체**（haeyoche）、「ヘヨ体」と呼ばれています。うれしいことに、ひとつの形で平叙文も疑問文も、さらには勧誘まで表せます。

## ステップ1：語幹を見つける

韓国語の動詞と形容詞は、辞書では**-다**（-da）で終わる形で載っています。다を取ったものが語幹です。

- **가다**（gada）＝行く → 語幹 가-
- **먹다**（meokda）＝食べる → 語幹 먹-
- **좋다**（jota）＝良い → 語幹 좋-

## ステップ2：最後の母音を見る

次に、**語幹の最後の音節**の母音を見ます。

- **ㅏ**か**ㅗ**なら、**-아요**をつけます。
- それ以外なら、**-어요**をつけます。
- **하다**で終わる動詞は、**해요**になります。

| 辞書形 | 語幹の母音 | 丁寧形 | 意味 |
|---|---|---|---|
| 살다 (salda) | ㅏ | 살아요 (sarayo) | 住みます |
| 좋다 (jota) | ㅗ | 좋아요 (joayo) | 良いです |
| 먹다 (meokda) | ㅓ | 먹어요 (meogeoyo) | 食べます |
| 읽다 (ikda) | ㅣ | 읽어요 (ilgeoyo) | 読みます |
| 있다 (itda) | ㅣ | 있어요 (isseoyo) | あります／います、持っています |
| 공부하다 (gongbuhada) | 하다 | 공부해요 (gongbuhaeyo) | 勉強します |

最後の行は「不規則」に見えますが、完全に予測できます。하다動詞はすべてこの形になるからです。**일하다**（ilhada）＝働く → **일해요**（ilhaeyo）、**좋아하다**（joahada）＝好きだ → **좋아해요**（joahaeyo）。

## ステップ3：母音をくっつける

語幹が母音で終わる場合、2つの母音はたいていぎゅっと縮まります。よく使う形の多くが予想と違って見えるのはこのためです。

- 가 + 아요 → **가요**（gayo）＝2つのㅏがひとつになる
- 서 + 어요 → **서요**（seoyo）＝立ちます／止まります
- 오 + 아요 → **와요**（wayo）＝来ます
- 보 + 아요 → **봐요**（bwayo）＝見ます
- 배우 + 어요 → **배워요**（baewoyo）＝習います
- 마시 + 어요 → **마셔요**（masyeoyo）＝飲みます
- 되 + 어요 → **돼요**（dwaeyo）＝できます／大丈夫です
- 보내 + 어요 → **보내요**（bonaeyo）＝送ります

語幹が**ㅡ**で終わる場合は、ㅡを落としてから、その前の音節を見ます。

- 쓰다（sseuda）＝書く → **써요**（sseoyo）
- 바쁘다（bappeuda）＝忙しい → **바빠요**（bappayo）。前の音節が바なので
- 예쁘다（yeppeuda）＝きれいだ → **예뻐요**（yeppeoyo）

いくつかの動詞は本当に不規則です。たとえば**덥다**（deopda）＝暑い → **더워요**（deowoyo）、**모르다**（moreuda）＝知らない → **몰라요**（mollayo）など。出会ったときに覚えていけば大丈夫です。ほとんどの動詞は上のルールで対応できます。

## ひとつの形で3つの役割

同じ形で、いろいろなタイプの文を作れます。変わるのはイントネーションだけです。

- **平叙文：** 지금 가요.（Jigeum gayo.）＝今行きます。
- **疑問文：** 지금 가요?（Jigeum gayo?）＝今行きますか？（語尾を上げる）
- **勧誘：** 같이 가요!（Gachi gayo!）＝一緒に行きましょう！

ここには「わたし」や「あなた」にあたる単語がありません。韓国語では、文脈から明らかなときは主語を省略するのが普通です。

## どんな場面で使う？

**요**を取るとタメ口（반말、banmal）になります：가、먹어、해。これは親しい友だちや年下の人に使います。逆に、**갑니다**（gamnida）のような**-습니다**（-seumnida）形はよりかしこまった言い方で、ニュースやアナウンス、ビジネスでよく使われます。ほとんどの学習者にとって、**-아요/어요**がいちばん無難な基本形です。

## ミニ練習

次の動詞を-아요/어요形に変えてみましょう。答えは下にあります。

1. 앉다（anda）＝座る
2. 마시다（masida）＝飲む
3. 일하다（ilhada）＝働く
4. 만나다（mannada）＝会う
5. 주다（juda）＝あげる、くれる
6. 크다（keuda）＝大きい

**答え：** 1. 앉아요 (anjayo) 2. 마셔요 (masyeoyo) 3. 일해요 (ilhaeyo) 4. 만나요 (mannayo) 5. 줘요 (jwoyo) 6. 커요 (keoyo)

## 使える韓国語

| 韓国語 | ローマ字 | 意味 |
|---|---|---|
| [좋아요](/ja/dictionary/?q=좋다) | joayo | 良いです／好きです |
| 괜찮아요 | gwaenchanayo | 大丈夫です |
| 몰라요 | mollayo | 知りません、わかりません |
| [먹어요](/ja/dictionary/?q=먹다) | meogeoyo | 食べます |
| 뭐 해요? | mwo haeyo? | 何していますか？ |
| 같이 가요! | gachi gayo! | 一緒に行きましょう！ |

-아요/어요だけを使って、自分の1日を5つの短い文で説明してみましょう。ひとつの語尾でここまで言えるのかと、きっと驚きますよ。
