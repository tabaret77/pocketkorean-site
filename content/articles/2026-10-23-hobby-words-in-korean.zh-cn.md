无论是在语言交换活动上、上班第一天，还是在韩剧里的相亲场合，迟早会有人问你：**취미가 뭐예요?**（Chwimiga mwoyeyo?）——你的爱好是什么？这是韩语里最常见的闲聊问题之一。**[취미](/zh-cn/dictionary/?q=취미)**（chwimi）是爱好的意思，而深秋凉爽的天气正适合培养一个新爱好。很多人把秋天称为**독서의 계절**（doksseoui gyejeol [독써의 계절]）——读书的季节——因为晴朗凉爽的日子最适合静下心来读一本书。下面是聊业余爱好时需要用到的词汇和句型。

## 24个爱好词汇

很多爱好是名词，加上**하다**（hada，做）就变成动词。还有一些是动词加**-기**（-gi）变成的名词，比如**사진 찍기**，“拍照”。

| 韩语 | 罗马音 | 意思 |
|---|---|---|
| 등산 | deungsan | 登山，爬山 |
| 독서 | doksseo [독써] | 读书 |
| 요리 | yori | 做饭，烹饪 |
| 운동 | undong | 运动 |
| 헬스 | helseu | 去健身房健身 |
| 요가 | yoga | 瑜伽 |
| 수영 | suyeong | 游泳 |
| 산책 | sanchaek | 散步 |
| 자전거 타기 | jajeongeo tagi | 骑自行车 |
| 캠핑 | kaemping | 露营 |
| 낚시 | nakssi [낙씨] | 钓鱼 |
| 여행 | yeohaeng | 旅行 |
| 사진 찍기 | sajin jjikki [사진 찍끼] | 拍照 |
| 그림 그리기 | geurim geurigi | 画画 |
| 뜨개질 | tteugaejil | 织毛衣，编织 |
| 베이킹 | beiking | 烘焙 |
| 게임 | geim | （电子）游戏 |
| 영화 보기 | yeonghwa bogi | 看电影 |

| 춤 | chum | 跳舞 |
| 악기 연주 | akki yeonju [악끼 연주] | 演奏乐器 |
| 피아노를 치다 | pianoreul chida | 弹钢琴 |
| 기타를 치다 | gitareul chida | 弹吉他 |

钢琴、吉他这类敲击或拨弦的乐器，要用**치다**（chida），而不是**하다**。

## 两种回答方式

**1. 제 취미는 + 名词 + 이에요/예요.** 最简单的回答就是直接说出爱好：

- **제 취미는 등산이에요.**（Je chwimineun deungsanieyo.）——我的爱好是登山。
- **제 취미는 요리예요.**（Je chwimineun yoriyeyo.）——我的爱好是做饭。

如果是一个动作，就用**-기**把动词变成名词。取动词词干，加上**-기**：**읽다** → **읽기**，**찍다** → **찍기**。

- **제 취미는 책 읽기예요.**（Je chwimineun chaek ilkkiyeyo. [책 일끼예요.]）——我的爱好是看书。
- **제 취미는 사진 찍기예요.**（Je chwimineun sajin jjikkiyeyo. [제 취미는 사진 찍끼예요.]）——我的爱好是拍照。

**2. -는 것을 좋아해요.** 要说“我喜欢做……”，就在动词词干后加上**-는 것을 좋아해요**。口语里，**것을**通常缩略成**걸**。

| 动词 | + -는 것을 좋아해요 | 意思 |
|---|---|---|
| 요리하다 (yorihada) | 요리하는 것을 좋아해요 (yorihaneun geoseul joahaeyo) | 我喜欢做饭 |
| [걷다](/zh-cn/dictionary/?q=걷다) (geotta [걷따]) | 걷는 걸 좋아해요 (geonneun geol joahaeyo) | 我喜欢走路 |
| 듣다 (deutta [듣따]) | 음악 듣는 걸 좋아해요 (eumak deunneun geol joahaeyo) | 我喜欢听音乐 |
| 만들다 (mandeulda) | 만드는 걸 좋아해요 (mandeuneun geol joahaeyo) | 我喜欢做东西 |
| 그리다 (geurida) | 그림 그리는 걸 좋아해요 (geurim geurineun geol joahaeyo) | 我喜欢画画 |

两点说明：以**ㄹ**结尾的词干在**-는**前面要脱落ㄹ（**만들다** → **만드는**）；词尾的ㄷ或ㄱ在**는**前面分别读成ㄴ或ㅇ：**걷는**[건는]，**듣는**[든는]。

## 继续追问

- **시간 있을 때 뭐 해요?**（Sigan isseul ttae mwo haeyo?）——有空的时候你做什么？
- **주말에 보통 뭐 해요?**（Jumare botong mwo haeyo?）——周末你一般做什么？
- **얼마나 자주 해요?**（Eolmana jaju haeyo?）——你多久做一次？
- **같이 할래요?**（Gachi hallaeyo?）——要不要一起？

回答频率时可以用：**매일**（maeil）——每天，**일주일에 두 번**（iljuire du beon）——一周两次，**가끔**（gakkeum）——偶尔。

## 注意发音

- **독서**读作[독써]：收音ㄱ后面的ㅅ变成紧音。
- **낚시**读作[낙씨]（naksi）。
- **악기**读作[악끼]（akgi）。

| 등산하는 걸 좋아해요 | deungsanhaneun geol joahaeyo | 我喜欢爬山 |

**저는 ___는 걸 좋아해요.**（Jeoneun ___neun geol joahaeyo.）——我喜欢___。用这个句型写三句关于你自己爱好的话，然后问问别人：**취미가 뭐예요?**
