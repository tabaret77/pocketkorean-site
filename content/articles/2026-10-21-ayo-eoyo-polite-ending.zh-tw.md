如果韓語的動詞語尾你只學一個，那就學 **-아요/어요**（-ayo/-eoyo）吧。這是韓國人對店員、同事、剛認識的人，以及大多數不熟的人使用的親切禮貌語體。在文法書裡，它叫做 **해요체**（haeyoche），也就是「해요體」。好消息是：一種形式就能用在陳述句、疑問句，甚至提議句。

## 步驟1：找出語幹

韓語的動詞和形容詞在字典裡都以 **-다**（-da）結尾。把 다 拿掉，剩下的就是語幹：

- **가다**（gada）——去 → 語幹 가-
- **먹다**（meokda）——吃 → 語幹 먹-
- **좋다**（jota）——好 → 語幹 좋-

## 步驟2：看最後一個母音

接著看 **語幹最後一個音節** 的母音。

- 如果是 **ㅏ** 或 **ㅗ**，就加 **-아요**。
- 如果是其他母音，就加 **-어요**。
- 如果動詞以 **하다** 結尾，就變成 **해요**。

| 原形 | 語幹母音 | 禮貌形 | 意思 |
|---|---|---|---|
| 살다 (salda) | ㅏ | 살아요 (sarayo) | （我）住 |
| 좋다 (jota) | ㅗ | 좋아요 (joayo) | （很）好 |
| 먹다 (meokda) | ㅓ | 먹어요 (meogeoyo) | （我）吃 |
| 읽다 (ikda) | ㅣ | 읽어요 (ilgeoyo) | （我）讀 |
| 있다 (itda) | ㅣ | 있어요 (isseoyo) | 有／（我）有 |
| 공부하다 (gongbuhada) | 하다 | 공부해요 (gongbuhaeyo) | （我）讀書 |

最後一行看起來很「不規則」，但其實完全可以預測：所有 하다 動詞都照這個規則變化。**일하다**（ilhada）——工作 → **일해요**（ilhaeyo）；**좋아하다**（joahada）——喜歡 → **좋아해요**（joahaeyo）。

## 步驟3：讓母音合併

當語幹以母音結尾時，兩個母音通常會擠在一起。這就是為什麼很多常用的形式看起來跟你預想的不一樣：

- 가 + 아요 → **가요**（gayo）——兩個 ㅏ 音合併
- 서 + 어요 → **서요**（seoyo）——（我）站／停
- 오 + 아요 → **와요**（wayo）——（我）來
- 보 + 아요 → **봐요**（bwayo）——（我）看
- 배우 + 어요 → **배워요**（baewoyo）——（我）學
- 마시 + 어요 → **마셔요**（masyeoyo）——（我）喝
- 되 + 어요 → **돼요**（dwaeyo）——可以／行得通
- 보내 + 어요 → **보내요**（bonaeyo）——（我）寄、送

語幹以 **ㅡ** 結尾的，要先去掉 ㅡ，再看前一個音節：

- 쓰다（sseuda）——寫 → **써요**（sseoyo）
- 바쁘다（bappeuda）——忙 → **바빠요**（bappayo），因為前一個音節是 바
- 예쁘다（yeppeuda）——漂亮 → **예뻐요**（yeppeoyo）

有少數動詞是真正的不規則變化，例如 **덥다**（deopda）——熱 → **더워요**（deowoyo），或 **모르다**（moreuda）——不知道 → **몰라요**（mollayo）。遇到再記就好；上面的規則已經能處理大部分的動詞。

## 一種形式，三種用法

同一個形式可以用在不同的句型，只要改變語調就好。

- **陳述句：** 지금 가요.（Jigeum gayo.）——我現在要走了。
- **疑問句：** 지금 가요?（Jigeum gayo?）——你現在要走嗎？（語調上揚）
- **提議句：** 같이 가요!（Gachi gayo!）——一起去吧！

這裡沒有另外用到「我」或「你」；只要從上下文看得出來，韓語通常會省略主詞。

## 它的定位

把 **요** 拿掉，就變成半語（반말，banmal）：가、먹어、해。這是對很熟的朋友和比你年紀小的人用的。反過來，像 **갑니다**（gamnida）這種 **-습니다**（-seumnida）形式則更正式，常見於新聞、廣播和商務場合。對大多數學習者來說，**-아요/어요** 是最保險的預設選擇。

## 小練習

把下面每個動詞改成 -아요/어요 形。答案在下方。

1. 앉다（anda）——坐
2. 마시다（masida）——喝
3. 일하다（ilhada）——工作
4. 만나다（mannada）——見面
5. 주다（juda）——給
6. 크다（keuda）——大

**答案：** 1. 앉아요（anjayo） 2. 마셔요（masyeoyo） 3. 일해요（ilhaeyo） 4. 만나요（mannayo） 5. 줘요（jwoyo） 6. 커요（keoyo）

## 實用韓語

| 韓語 | 羅馬拼音 | 意思 |
|---|---|---|
| [좋아요](/zh-tw/dictionary/?q=좋다) | joayo | （很）好／我喜歡 |
| 괜찮아요 | gwaenchanayo | 沒關係 |
| 몰라요 | mollayo | 我不知道 |
| [먹어요](/zh-tw/dictionary/?q=먹다) | meogeoyo | （我）吃 |
| 뭐 해요? | mwo haeyo? | 你在做什麼？ |
| 같이 가요! | gachi gayo! | 一起去吧！ |

試著只用 -아요/어요，以五個短句描述你的一天。你會驚訝地發現，光靠一個語尾就能表達這麼多。
