韓文乍看像一堵由小方格砌成的牆，但這些方格其實由一小組字母組成。**[한글](/zh-hk/dictionary/?q=한글)**（hangeul）——韓文字母——本來就是為了易學而設計的。它在世宗大王主持下創製，於1446年以 **훈민정음**（Hunminjeongeum，訓民正音）之名頒布，意思是「教導百姓的正確字音」。給自己一小時，你就能讀出招牌和餐牌上的字。

## 14個基本子音

有幾個子音的形狀就是口腔的簡單圖畫：**ㄱ** 表示舌根碰到上顎，**ㄴ** 表示舌尖碰到牙齒後面，**ㅁ** 表示合上的嘴唇。加上筆畫就代表多送一口氣：**ㄱ → ㅋ**、**ㄷ → ㅌ**、**ㅂ → ㅍ**、**ㅈ → ㅊ**。

| 字母 | 發音 | 字母 | 發音 |
|---|---|---|---|
| ㄱ | g / k | ㅇ | 在開頭不發音，在結尾讀 ng |
| ㄴ | n | ㅈ | j |
| ㄷ | d / t | ㅊ | ch |
| ㄹ | r / l | ㅋ | k（送氣） |
| ㅁ | m | ㅌ | t（送氣） |
| ㅂ | b / p | ㅍ | p（送氣） |
| ㅅ | s | ㅎ | h |

平音 ㄱ、ㄷ、ㅂ 和 ㅈ 介乎英文的「g/k」、「d/t」、「b/p」和「j/ch」之間。在詞首時聽起來比較接近 k、t、p 和 ch；夾在元音之間時就會軟化成 g、d、b 和 j。這就是為甚麼 **김치**（gimchi）——泡菜——在官方羅馬拼音中以 g 拼寫，但在講英文的人聽來卻像「kimchi」。

## 10個基本母音

母音由三個概念組成：一點或一短畫（天）、一條橫線 **ㅡ**（地），以及一條直線 **ㅣ**（人）。多加一短畫，就會加上「y」音。

| 母音 | 發音 | 母音 | 發音 |
|---|---|---|---|
| ㅏ | a（如英文「father」） | ㅗ | o |
| ㅑ | ya | ㅛ | yo |
| ㅓ | eo（像嘴唇略圓的「uh」） | ㅜ | u（如英文「moon」） |
| ㅕ | yeo | ㅠ | yu |
| ㅣ | i（如英文「ski」） | ㅡ | eu（不笑着讀「ee」） |

這就是24個字母。另外還有五個雙子音（ㄲ、ㄸ、ㅃ、ㅆ、ㅉ）和十一個複合母音，例如 **ㅐ**（ae）、**ㅔ**（e）和 **ㅘ**（wa），不過它們都由基本字母組成，之後很容易學會。

## 砌出一個音節方塊

韓文不像英文那樣把字母排成一行，而是每個音節組成一個方塊。每個方塊最少有一個子音和一個母音，而母音的形狀決定它放在哪裏。

**1. 直身的母音（ㅏ ㅑ ㅓ ㅕ ㅣ）放在子音右邊。**

- ㄴ + ㅏ = **나**（na）
- ㅁ + ㅓ = **머**（meo）

**2. 扁身的母音（ㅗ ㅛ ㅜ ㅠ ㅡ）放在下面。**

- ㄱ + ㅗ = **고**（go）
- ㄴ + ㅜ = **누**（nu）

**3. 以母音開頭的音節，用不發音的 ㅇ 來佔位。**

- ㅇ + ㅏ = **아**（a）
- ㅇ + ㅜ = **우**（u）

母音不能單獨組成方塊，所以由 ㅇ 填補空出來的子音位置。

**4. 收尾的子音放在最底。** 這個底部的子音叫做 **받침**（batchim），意思是「支撐」。

- ㅎ + ㅏ + ㄴ = **한**（han）
- ㄱ + ㅜ + ㄱ = **국**（guk）
- 한 + 국 = **한국**（Hanguk）——韓國

在方塊底部時，ㅇ 讀作「ng」：**강**（gang）——河。

## 練習閱讀

遮住羅馬拼音試試讀以下的字。它們只用了24個基本字母：

| 韓語 | 羅馬拼音 | 意思 |
|---|---|---|
| 나무 | namu | 樹 |
| 바다 | bada | 海 |
| 우유 | uyu | 牛奶 |
| 서울 | Seoul | 首爾 |
| 사랑 | sarang | 愛 |
| 친구 | chingu | 朋友 |
| 라면 | ramyeon | 即食麵 |
| 한국어 | hangugeo | 韓語 |

留意在 **한국어** 中，국 的收尾音 ㄱ 會滑到下一個音節，因為 어 以不發音的 ㅇ 開頭：所以讀作「han-gu-geo」。每當收尾子音遇上母音，韓語都會這樣連音，令說話更流暢。

## 第一小時的小貼士

- **先學母音。** 只有十個，而且是每個方塊的骨幹。
- **讀真實的詞語，不只是字母。** 店舖招牌、地鐵站名和K-pop歌名都是絕佳的練習材料。
- **親手寫每個方塊。** 筆順一般是由上至下、由左至右。
- **不要長期依賴羅馬拼音。** 它是一枝拐杖，可能會掩蓋真正的發音，尤其是 ㅓ 和 ㅡ。

## 實用韓語

| 韓語 | 羅馬拼音 | 意思 |
|---|---|---|
| 한글 | hangeul | 韓文字母 |
| 자음 | jaeum | 子音 |
| 모음 | moeum | 母音 |
| 받침 | batchim | 收尾子音 |
| [읽다](/zh-hk/dictionary/?q=읽다) | ikda | 讀 |
| 이거 어떻게 읽어요? | igeo eotteoke ilgeoyo? | 這個怎樣讀？ |

一旦掌握了方塊的組合方法，你遇到的每一個韓文字都能讀出來——這才是學韓語真正的起點。
