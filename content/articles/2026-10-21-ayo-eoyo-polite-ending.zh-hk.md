如果韓語動詞語尾你只學一個，那就學 **-아요/어요**（-ayo/-eoyo）。這是韓國人對店員、同事、剛認識的人，以及大部分不太熟的人所用的親切又有禮貌的說話方式。文法書稱之為 **해요체**（haeyoche），即「해요體」。好消息是：一個形式就可以用於陳述句、疑問句，甚至提議。

## 第1步：找出詞幹

韓語的動詞和形容詞在字典中都以 **-다**（-da）結尾。去掉 다，剩下的就是詞幹：

- **가다**（gada）——去 → 詞幹 가-
- **먹다**（meokda）——吃 → 詞幹 먹-
- **좋다**（jota）——好 → 詞幹 좋-

## 第2步：看最後一個元音

接着看 **詞幹最後一個音節** 的元音。

- 如果是 **ㅏ** 或 **ㅗ**，加 **-아요**。
- 如果是其他元音，加 **-어요**。
- 如果動詞以 **하다** 結尾，就變成 **해요**。

| 字典形 | 詞幹元音 | 禮貌形 | 意思 |
|---|---|---|---|
| 살다 (salda) | ㅏ | 살아요 (sarayo) | （我）住 |
| 좋다 (jota) | ㅗ | 좋아요 (joayo) | （這個）好 |
| 먹다 (meokda) | ㅓ | 먹어요 (meogeoyo) | （我）吃 |
| 읽다 (ikda) | ㅣ | 읽어요 (ilgeoyo) | （我）讀 |
| 있다 (itda) | ㅣ | 있어요 (isseoyo) | 有／（我）有 |
| 공부하다 (gongbuhada) | 하다 | 공부해요 (gongbuhaeyo) | （我）讀書 |

最後一行看起來好像「不規則」，但其實完全有規律可循：所有 하다 動詞都是這樣變。**일하다**（ilhada）——工作 → **일해요**（ilhaeyo）；**좋아하다**（joahada）——喜歡 → **좋아해요**（joahaeyo）。

## 第3步：讓元音合併

當詞幹以元音結尾時，兩個元音通常會擠在一起。這就是為甚麼很多常用形式和你預期的不一樣：

- 가 + 아요 → **가요**（gayo）——兩個 ㅏ 音合而為一
- 서 + 어요 → **서요**（seoyo）——（我）站／停
- 오 + 아요 → **와요**（wayo）——（我）來
- 보 + 아요 → **봐요**（bwayo）——（我）看
- 배우 + 어요 → **배워요**（baewoyo）——（我）學
- 마시 + 어요 → **마셔요**（masyeoyo）——（我）喝
- 되 + 어요 → **돼요**（dwaeyo）——（這樣）可以／行得通
- 보내 + 어요 → **보내요**（bonaeyo）——（我）寄、傳送

以 **ㅡ** 結尾的詞幹會去掉 ㅡ，然後看前一個音節：

- 쓰다（sseuda）——寫 → **써요**（sseoyo）
- 바쁘다（bappeuda）——忙 → **바빠요**（bappayo），因為前一個音節是 바
- 예쁘다（yeppeuda）——漂亮 → **예뻐요**（yeppeoyo）

有少數動詞是真正的不規則動詞，例如 **덥다**（deopda）——熱 → **더워요**（deowoyo），或 **모르다**（moreuda）——不知道 → **몰라요**（mollayo）。遇到時再記就可以；以上規則已經能應付大部分動詞。

## 一個形式，三種用途

同一個形式可以用於不同句型，只是語調不同。

- **陳述：** 지금 가요.（Jigeum gayo.）——我現在去。
- **疑問：** 지금 가요?（Jigeum gayo?）——你現在去嗎？（語調上揚）
- **提議：** 같이 가요!（Gachi gayo!）——一起去吧！

這裏沒有獨立表示「我」或「你」的字；只要從語境看得出來，韓語通常會省略主語。

## 它的位置

去掉 **요**，就變成半語（반말，banmal）：가、먹어、해。這是對好朋友和比自己年輕的人用的。反過來，**-습니다**（-seumnida）形式例如 **갑니다**（gamnida）就更正式，常見於新聞、廣播和商務場合。對大部分學習者來說，**-아요/어요** 是最穩妥的預設選擇。

## 小練習

把以下動詞變成 -아요/어요 形式。答案在下面。

1. 앉다（anda）——坐
2. 마시다（masida）——喝
3. 일하다（ilhada）——工作
4. 만나다（mannada）——見面
5. 주다（juda）——給
6. 크다（keuda）——大

**答案：** 1. 앉아요（anjayo） 2. 마셔요（masyeoyo） 3. 일해요（ilhaeyo） 4. 만나요（mannayo） 5. 줘요（jwoyo） 6. 커요（keoyo）

## 實用韓語

| 韓語 | 羅馬拼音 | 意思 |
|---|---|---|
| [좋아요](/zh-hk/dictionary/?q=좋다) | joayo | 好／我喜歡 |
| 괜찮아요 | gwaenchanayo | 不要緊 |
| 몰라요 | mollayo | 我不知道 |
| [먹어요](/zh-hk/dictionary/?q=먹다) | meogeoyo | （我）吃 |
| 뭐 해요? | mwo haeyo? | 你在做甚麼？ |
| 같이 가요! | gachi gayo! | 一起去吧！ |

試試只用 -아요/어요，以五句短句描述你的一天。你會驚訝一個語尾原來可以帶你走這麼遠。
