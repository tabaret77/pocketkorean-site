如果韩语的动词词尾你只学一个，那就学**-아요/어요**（-ayo/-eoyo）。这是一种亲切又礼貌的说话方式，韩国人对店员、同事、新认识的人以及大多数不太熟的人都会这样说。语法书里把它叫作**해요체**（haeyoche），即“해요体”。好消息是：同一个形式就能表达陈述、疑问，甚至提议。

## 第1步：找到词干

韩语的动词和形容词在词典里都以**-다**（-da）结尾。去掉다，剩下的就是词干：

- **가다**（gada）——去 → 词干가-
- **먹다**（meokta [먹따]）——吃 → 词干먹-
- **좋다**（jota）——好 → 词干좋-

## 第2步：看最后一个元音

接着看**词干最后一个音节**里的元音。

- 如果是**ㅏ**或**ㅗ**，加**-아요**。
- 如果是其他元音，加**-어요**。
- 如果动词以**하다**结尾，就变成**해요**。

| 词典形 | 词干元音 | 敬语形 | 意思 |
|---|---|---|---|
| 살다 (salda) | ㅏ | 살아요 (sarayo) | （我）住、生活 |
| 좋다 (jota) | ㅗ | 좋아요 (joayo) | （很）好 |
| 먹다 (meokta [먹따]) | ㅓ | 먹어요 (meogeoyo) | （我）吃 |
| 읽다 (ikta [익따]) | ㅣ | 읽어요 (ilgeoyo) | （我）读 |
| 있다 (itta [읻따]) | ㅣ | 있어요 (isseoyo) | 有／在 |
| 공부하다 (gongbuhada) | 하다 | 공부해요 (gongbuhaeyo) | （我）学习 |

最后一行看起来像是“不规则”的，但其实完全有规律可循：所有하다动词都这样变。**일하다**（ilhada）——工作 → **일해요**（ilhaeyo）；**좋아하다**（joahada）——喜欢 → **좋아해요**（joahaeyo）。

## 第3步：让元音合并

当词干以元音结尾时，两个元音通常会挤在一起合并。这就是为什么很多常用形式和你预想的不一样：

- 가 + 아요 → **가요**（gayo）——两个ㅏ合二为一
- 서 + 어요 → **서요**（seoyo）——（我）站、停
- 오 + 아요 → **와요**（wayo）——（我）来
- 보 + 아요 → **봐요**（bwayo）——（我）看
- 배우 + 어요 → **배워요**（baewoyo）——（我）学
- 마시 + 어요 → **마셔요**（masyeoyo）——（我）喝
- 되 + 어요 → **돼요**（dwaeyo）——行、可以
- 보내 + 어요 → **보내요**（bonaeyo）——（我）寄、发送

以**ㅡ**结尾的词干会去掉ㅡ，再看它前面的那个音节：

- 쓰다（sseuda）——写 → **써요**（sseoyo）
- 바쁘다（bappeuda）——忙 → **바빠요**（bappayo），因为前面的音节是바
- 예쁘다（yeppeuda）——漂亮 → **예뻐요**（yeppeoyo）

也有少数动词是真正的不规则变化，比如**덥다**（deopta [덥따]）——热 → **더워요**（deowoyo），或**모르다**（moreuda）——不知道 → **몰라요**（mollayo）。遇到一个记一个就好；大多数动词用上面的规则就能搞定。

## 一个形式，三种用法

同一个形式可以用在不同的句型里，只是语调不同。

- **陈述：**지금 가요.（Jigeum gayo.）——我现在走。
- **疑问：**지금 가요?（Jigeum gayo?）——你现在走吗？（语调上扬）
- **提议：**같이 가요!（Gachi gayo!）——一起走吧！

这里没有单独表示“我”或“你”的词；在语境清楚时，韩语通常会省略主语。

## 它处在什么位置

去掉**요**，就是非敬语（반말，banmal）：가、먹어、해。这是对亲密朋友和比自己小的人说的。反过来，像**갑니다**（gamnida）这样的**-습니다**（-seumnida）形式更加正式，常见于新闻、广播通知和商务场合。对大多数学习者来说，**-아요/어요**是最稳妥的默认选择。

## 小练习

把下面每个动词变成-아요/어요形式。答案在下面。

1. 앉다（antta [안따]）——坐
2. 마시다（masida）——喝
3. 일하다（ilhada）——工作
4. 만나다（mannada）——见面
5. 주다（juda）——给
6. 크다（keuda）——大

**答案：**1. 앉아요（anjayo） 2. 마셔요（masyeoyo） 3. 일해요（ilhaeyo） 4. 만나요（mannayo） 5. 줘요（jwoyo） 6. 커요（keoyo）

## 可以直接用的韩语

| 韩语 | 罗马音 | 意思 |
|---|---|---|
| [좋아요](/zh-cn/dictionary/?q=좋다) | joayo | （很）好／我喜欢 |
| 괜찮아요 | gwaenchanayo | 没关系 |
| 몰라요 | mollayo | 我不知道 |
| [먹어요](/zh-cn/dictionary/?q=먹다) | meogeoyo | （我）吃 |
| 뭐 해요? | mwo haeyo? | 你在做什么？ |
| 같이 가요! | gachi gayo! | 一起走吧！ |

试着只用-아요/어요，用五个短句描述你的一天。你会惊讶地发现，一个词尾就能让你说这么多。
