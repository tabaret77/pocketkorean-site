「你周末做了甚麼？」大概是在韓國星期一最常聽到的問題。要回答它，你需要過去式，而好消息是，過去式建基於你可能已經學過的東西：現在式詞尾 **-아요/어요**。把 **요** 換成 **ㅆ어요**，就變成過去式。**가요**（gayo）——我去——就變成 **갔어요**（gasseoyo）——我去了。

## 基本規則

取動詞詞幹（字典形去掉 **-다**），看它最後一個元音：

- 最後元音是 **ㅏ 或 ㅗ** → 加 **-았어요**（-asseoyo）
- 其他元音 → 加 **-었어요**（-eosseoyo）
- 以 **하다** 結尾的 → **했어요**（haesseoyo）

這和現在式的元音選擇完全一樣，所以只要你會說 **먹어요**，就會說 **먹었어요**。

| 字典形 | 詞幹 | 過去式（禮貌） | 意思 |
|---|---|---|---|
| [살다](/zh-hk/dictionary/?q=살다) (salda) | 살- | 살았어요 (sarasseoyo) | 我住過／我生活了 |
| 좋다 (jota) | 좋- | 좋았어요 (joasseoyo) | 很好（過去） |
| [먹다](/zh-hk/dictionary/?q=먹다) (meokta [먹따]) | 먹- | 먹었어요 (meogeosseoyo) | 我吃了 |
| 읽다 (ikta [익따]) | 읽- | 읽었어요 (ilgeosseoyo) | 我讀了 |
| 맛있다 (masitta [마싣따]) | 맛있- | 맛있었어요 (masisseosseoyo) | 很好吃（過去） |
| [공부하다](/zh-hk/dictionary/?q=공부하다) (gongbuhada) | 공부하- | 공부했어요 (gongbuhaesseoyo) | 我讀了書 |
| 일하다 (ilhada) | 일하- | 일했어요 (ilhaesseoyo) | 我工作了 |

## 會合併的元音

詞幹以元音結尾時，兩個元音通常會擠在一起，和現在式一樣：

| 字典形 | 過去式（禮貌） | 變化過程 |
|---|---|---|
| [가다](/zh-hk/dictionary/?q=가다) (gada) | 갔어요 (gasseoyo) | 가 + 았 → 갔 |
| 오다 (oda) | 왔어요 (wasseoyo) | 오 + 았 → 왔 |
| [보다](/zh-hk/dictionary/?q=보다) (boda) | 봤어요 (bwasseoyo) | 보 + 았 → 봤 |
| 마시다 (masida) | 마셨어요 (masyeosseoyo) | 시 + 었 → 셨 |
| 배우다 (baeuda) | 배웠어요 (baewosseoyo) | 우 + 었 → 웠 |
| 서다 (seoda) | 섰어요 (seosseoyo) | 서 + 었 → 섰 |
| 보내다 (bonaeda) | 보냈어요 (bonaesseoyo) | 내 + 었 → 냈 |

少數詞幹，例如 **쉬다**（swida）——休息——不會合併：**쉬었어요**（swieosseoyo）。

## 名詞：이었어요 / 였어요

要用名詞說「是……（過去）」，子音後用 **이었어요**，元音後用 **였어요**：

- **어제는 제 생일이었어요.**（Eojeneun je saengirieosseoyo.）——昨天是我的生日。
- **그 사람은 제 친구였어요.**（Geu sarameun je chinguyeosseoyo.）——那個人曾經是我的朋友。

## 不規則動詞保留原本的特點

不規則動詞在過去式中的變化和現在式完全一樣，所以要成對地記：

- **듣다**（deutta [듣따]）——聽 → 들었어요（deureosseoyo）
- **춥다**（chupta [춥따]）——冷 → 추웠어요（chuwosseoyo）
- **바쁘다**（bappeuda）——忙 → 바빴어요（bappasseoyo）
- **쓰다**（sseuda）——寫、使用 → 썼어요（sseosseoyo）
- **모르다**（moreuda）——不知道 → 몰랐어요（mollasseoyo）

## 否定過去式

在過去式動詞前面加 **안**（不）或 **못**（不能）：

- **아침을 안 먹었어요.**（Achimeul an meogeosseoyo.）——我沒有吃早餐。
- **어제 못 잤어요.**（Eoje mot jasseoyo.）——我昨晚睡不着。

**하다** 動詞的否定詞要放在 **했어요** 正前方：**공부 안 했어요**（gongbu an haesseoyo）——我沒有讀書。

## 搭配的時間詞

**어제**（eoje）——昨天，**지난주**（jinanju）——上星期，**주말에**（jumare）——周末，**작년**（jangnyeon）——去年。10月底正是練習的好時機：**주말에 단풍 구경 갔어요.**（Jumare danpung gugyeong gasseoyo.）——我周末去了看紅葉。

和朋友說話時用隨意語氣，只要去掉 **요**：**갔어**、**먹었어**、**뭐 했어?**

## 小練習

把以下改成禮貌過去式。答案在下面。

1. 만나다（見面）
2. 마시다（喝）
3. 청소하다（打掃）
4. 덥다（熱）
5. 학생（學生）+ 是（過去）

**答案：** 1. 만났어요（mannasseoyo） 2. 마셨어요（masyeosseoyo） 3. 청소했어요（cheongsohaesseoyo） 4. 더웠어요（deowosseoyo） 5. 학생이었어요（hakssaengieosseoyo [학쌩이어써요]）
