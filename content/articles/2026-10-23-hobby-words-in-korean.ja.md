言語交換の場でも、職場の初日でも、Kドラマのお見合いの場面でも、遅かれ早かれ誰かに**취미가 뭐예요?**（Chwimiga mwoyeyo?）＝趣味は何ですか？と聞かれるはずです。韓国語の雑談で最もよく出る質問のひとつです。**[취미](/ja/dictionary/?q=취미)**（chwimi）は趣味という意味で、涼しくなる晩秋は新しい趣味を始めるのにいい時期です。澄んだ涼しい日が続き、本を手にして落ち着きやすいことから、多くの人が秋を**독서의 계절**（dokseoui gyejeol）＝読書の季節と呼びます。日本語の「読書の秋」と同じですね。ここでは、好きなことについて話すのに必要な単語とパターンを紹介します。

## 趣味を表す24の単語

多くの趣味は、名詞に**하다**（hada）＝するをつけると動詞になります。ほかに、**사진 찍기**＝「写真を撮ること」のように、動詞に**-기**（-gi）をつけて名詞にしたものもあります。

| 韓国語 | ローマ字 | 意味 |
|---|---|---|
| 등산 | deungsan | 登山、山歩き |
| 독서 | dokseo | 読書 |
| 요리 | yori | 料理 |
| 운동 | undong | 運動、スポーツ |
| 헬스 | helseu | ジムでの筋トレ |
| 요가 | yoga | ヨガ |
| 수영 | suyeong | 水泳 |
| 산책 | sanchaek | 散歩 |
| 자전거 타기 | jajeongeo tagi | サイクリング |
| 캠핑 | kaemping | キャンプ |
| 낚시 | naksi | 釣り |
| 여행 | yeohaeng | 旅行 |
| 사진 찍기 | sajin jjikgi | 写真を撮ること |
| 그림 그리기 | geurim geurigi | 絵を描くこと |
| 뜨개질 | tteugaejil | 編み物 |
| 베이킹 | beiking | お菓子・パン作り |

ピアノやギターのように、たたいたり弦をはじいたりする楽器には、**하다**ではなく**치다**（chida）を使います。

## 2つの答え方

**1. 제 취미는＋名詞＋이에요/예요.** いちばん簡単な答え方は、趣味の名前を言うだけです。

- **제 취미는 등산이에요.**（Je chwimineun deungsanieyo.）＝わたしの趣味は登山です。
- **제 취미는 요리예요.**（Je chwimineun yoriyeyo.）＝わたしの趣味は料理です。

動作を言うときは、**-기**で動詞を名詞にします。語幹に**-기**をつけます：**읽다** → **읽기**、**찍다** → **찍기**。

- **제 취미는 책 읽기예요.**（Je chwimineun chaek ilgiyeyo.）＝わたしの趣味は本を読むことです。
- **제 취미는 사진 찍기예요.**（Je chwimineun sajin jjikgiyeyo.）＝わたしの趣味は写真を撮ることです。

**2. -는 것을 좋아해요.** 「〜するのが好きです」と言うには、動詞の語幹に**-는 것을 좋아해요**をつけます。話し言葉では、**것을**はふつう**걸**に縮まります。

| 動詞 | ＋-는 것을 좋아해요 | 意味 |
|---|---|---|
| 요리하다 (yorihada) | 요리하는 것을 좋아해요 (yorihaneun geoseul joahaeyo) | 料理するのが好きです |
| [걷다](/ja/dictionary/?q=걷다) (geotda) | 걷는 걸 좋아해요 (geonneun geol joahaeyo) | 歩くのが好きです |
| 듣다 (deutda) | 음악 듣는 걸 좋아해요 (eumak deunneun geol joahaeyo) | 音楽を聴くのが好きです |
| 만들다 (mandeulda) | 만드는 걸 좋아해요 (mandeuneun geol joahaeyo) | ものを作るのが好きです |
| 그리다 (geurida) | 그림 그리는 걸 좋아해요 (geurim geurineun geol joahaeyo) | 絵を描くのが好きです |

注意点が2つあります。**ㄹ**で終わる語幹は**-는**の前でㄹが落ちます（**만들다** → **만드는**）。また、**는**の前のパッチムㄷやㄱは、ㄴやㅇと発音されます：**걷는**[건는]、**듣는**[든는]。

## さらに質問してみよう

- **시간 있을 때 뭐 해요?**（Sigan isseul ttae mwo haeyo?）＝時間があるときは何をしますか？
- **주말에 보통 뭐 해요?**（Jumare botong mwo haeyo?）＝週末はふだん何をしますか？
- **얼마나 자주 해요?**（Eolmana jaju haeyo?）＝どのくらいの頻度でしますか？
- **같이 할래요?**（Gachi hallaeyo?）＝一緒にやりませんか？

頻度を答えるときは：**매일**（maeil）＝毎日、**일주일에 두 번**（iljuire du beon）＝週に2回、**가끔**（gakkeum）＝ときどき。

## 発音に注意

- **독서**は[독써]と発音します。パッチムㄱの後のㅅは濃音になります。
- **낚시**は[낙씨]（naksi）と発音します。
- **악기**は[악끼]（akgi）と発音します。

## 使える韓国語

| 韓国語 | ローマ字 | 意味 |
|---|---|---|
| 취미가 뭐예요? | chwimiga mwoyeyo? | 趣味は何ですか？ |
| 제 취미는 독서예요 | je chwimineun dokseoyeyo | わたしの趣味は読書です |
| 등산하는 걸 좋아해요 | deungsanhaneun geol joahaeyo | 登山が好きです |
| 요즘 뜨개질을 배워요 | yojeum tteugaejireul baewoyo | 最近、編み物を習っています |
| 게임을 자주 해요 | geimeul jaju haeyo | よくゲームをします |
| 같이 할래요? | gachi hallaeyo? | 一緒にやりませんか？ |

**저는 ___는 걸 좋아해요.**（Jeoneun ___neun geol joahaeyo.）＝わたしは___するのが好きです。自分の趣味について3つ文を書いてから、誰かに**취미가 뭐예요?**と聞いてみましょう。
