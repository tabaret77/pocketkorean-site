-아/어 달라고 하다

pedir (a alguém) que faça algo para si (pedido indireto)

Nível 3, TOPIK II · intermediário

Como usar

Citação indireta de um pedido '-아/어 주세요'. Quando quem pede é quem se beneficia, use 달라고; quando o benefício vai para uma terceira pessoa, use 주라고.

Como formar

돕다→ 도와 달라고 하다
사다→ 사 달라고 하다
기다리다→ 기다려 달라고 하다
보내다→ 보내 달라고 하다

✗ 동생이 저한테 숙제를 도와 주라고 했어요 (quando o irmão quer ajuda para ele mesmo) → 도와 달라고 했어요.

Exemplos

  • 친구가 숙제를 좀 도와 달라고 했어요.

    Meu amigo me pediu para ajudar com a lição de casa dele.

  • 아이가 장난감을 사 달라고 계속 졸라요.

    A criança fica me implorando para comprar um brinquedo para ela.

Comparado com formas parecidas

-(으)라고 하다 cita uma ordem simples; -아/어 달라고 하다 cita um pedido de favor. -아/어 주다 é a base 'fazer algo para alguém'.

Pratique com áudio e quizzes

O Pocket Korean tem gravações de nativos em todos os exemplos, revisão espaçada e simulados do TOPIK.

Padrões relacionados

  • -아/어 주다/드리다 fazer algo para alguém
