อ่านฮันกึลได้ในหนึ่งชั่วโมง: ตัวอักษร 24 ตัวและวิธีประกอบพยางค์

2026-10-21

ประโยคจากเรื่องนี้: 한글 = ฮันกึล ตัวอักษรเกาหลีค้นหาคำศัพท์

ตอนแรกภาษาเกาหลีอาจดูเหมือนกำแพงที่เต็มไปด้วยกล่องเล็กๆ แต่กล่องเหล่านั้นสร้างจากตัวอักษรเพียงไม่กี่ตัว 한글 (hangeul) – ตัวอักษรเกาหลี – ถูกออกแบบมาให้เรียนง่าย สร้างขึ้นในสมัยพระเจ้าเซจง และประกาศใช้ในปี 1446 ในชื่อ 훈민정음 (Hunminjeongeum) "เสียงที่ถูกต้องสำหรับสอนประชาชน" ให้เวลาสักหนึ่งชั่วโมง แล้วคุณจะเริ่มสะกดอ่านป้ายและเมนูได้

พยัญชนะพื้นฐาน 14 ตัว

รูปพยัญชนะหลายตัวเป็นภาพง่ายๆ ของปาก: ㄱ แสดงโคนลิ้นที่แตะเพดานปาก ㄴ ปลายลิ้นแตะหลังฟัน ㅁ ริมฝีปากที่ปิดอยู่ การเพิ่มขีดหมายถึงการเพิ่มลมพ่นออกมา: ㄱ → ㅋ, ㄷ → ㅌ, ㅂ → ㅍ, ㅈ → ㅊ

ข่าวดีสำหรับคนไทยคือ ภาษาไทยก็แยกเสียงมีลมกับไม่มีลมเหมือนกัน: ㄱ ใกล้กับ ก, ㄷ ใกล้กับ ต, ㅂ ใกล้กับ ป และ ㅈ ใกล้กับ จ ส่วน ㅋ ㅌ ㅍ ㅊ ใกล้กับ ค ท พ ช เมื่ออยู่ระหว่างสระ ㄱ ㄷ ㅂ ㅈ จะเบาลงเป็นเสียงก้องคล้าย g, d, b, j นี่คือเหตุผลที่ 김치 (gimchi) – กิมจิ – สะกดด้วย g ในระบบถอดอักษรโรมันอย่างเป็นทางการ แต่หูคนไทยได้ยินเป็น "กิมจิ"

สระพื้นฐาน 10 ตัว

รวมเป็น 24 ตัว นอกจากนี้ยังมีพยัญชนะคู่อีกห้าตัว (ㄲ, ㄸ, ㅃ, ㅆ, ㅉ) และสระประสมอีกสิบเอ็ดตัว เช่น ㅐ (แอ), ㅔ (เอ) และ ㅘ (วา) แต่ทั้งหมดสร้างจากตัวอักษรพื้นฐาน จึงเรียนตามได้ง่ายในภายหลัง

การประกอบบล็อกพยางค์

ภาษาเกาหลีไม่ได้เขียนตัวอักษรเรียงเป็นแถวแบบภาษาอังกฤษ แต่รวมเป็นหนึ่งบล็อกต่อหนึ่งพยางค์ ทุกบล็อกต้องมีพยัญชนะและสระอย่างน้อยอย่างละตัว และรูปร่างของสระจะเป็นตัวกำหนดว่าจะวางตรงไหน

1. สระแนวตั้ง (ㅏ ㅑ ㅓ ㅕ ㅣ) วางทางขวาของพยัญชนะ

  • ㄴ + ㅏ = 나 (na)
  • ㅁ + ㅓ = 머 (meo)

2. สระแนวนอน (ㅗ ㅛ ㅜ ㅠ ㅡ) วางข้างใต้

  • ㄱ + ㅗ = 고 (go)
  • ㄴ + ㅜ = 누 (nu)

3. พยางค์ที่ขึ้นต้นด้วยสระใช้ ㅇ ที่ไม่ออกเสียงเป็นตัวยึดตำแหน่ง

  • ㅇ + ㅏ = 아 (a)
  • ㅇ + ㅜ = 우 (u)

สระไม่สามารถอยู่ในบล็อกโดดๆ ได้ ㅇ จึงเข้ามาเติมช่องพยัญชนะที่ว่างอยู่ (คล้ายกับ อ ในภาษาไทย)

4. ตัวสะกดวางไว้ด้านล่าง พยัญชนะตัวล่างนี้เรียกว่า 받침 (batchim) "ตัวรองรับ"

  • ㅎ + ㅏ + ㄴ = 한 (han)
  • ㄱ + ㅜ + ㄱ = 국 (guk)
  • 한 + 국 = 한국 (Hanguk) – เกาหลี

เมื่ออยู่ด้านล่างของบล็อก ㅇ จะออกเสียงเป็น "ง": 강 (gang) – แม่น้ำ

สังเกตว่าใน 한국어 ตัวสะกด ㄱ ของ 국 จะเลื่อนไปยังพยางค์ถัดไป เพราะ 어 ขึ้นต้นด้วย ㅇ ที่ไม่ออกเสียง จึงอ่านว่า "ฮัน-กู-กอ" ภาษาเกาหลีทำแบบนี้ทุกครั้งที่ตัวสะกดเจอกับสระ ทำให้การพูดลื่นไหล

เคล็ดลับสำหรับชั่วโมงแรก

  • เรียนสระก่อน มีแค่สิบตัว และเป็นแกนหลักของทุกบล็อก
  • อ่านคำจริง ไม่ใช่แค่ตัวอักษร ป้ายร้านค้า ชื่อสถานีรถไฟใต้ดิน และชื่อเพลง K-pop เป็นแบบฝึกหัดชั้นดี
  • เขียนแต่ละบล็อกด้วยมือ ลำดับขีดโดยทั่วไปคือบนลงล่าง ซ้ายไปขวา
  • อย่าพึ่งคำอ่านโรมันนานเกินไป มันเป็นไม้ค้ำที่อาจบดบังเสียงจริง โดยเฉพาะ ㅓ และ ㅡ
