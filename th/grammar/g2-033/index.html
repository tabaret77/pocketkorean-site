N(이)라서

เพราะเป็น N (เหตุผลที่เป็นคำนาม)

ระดับ 2 · TOPIK I · ระดับต้น

วิธีใช้

คือ 이다 + -아/어서 ในรูปภาษาพูดที่ใช้บ่อย ใช้คำนามเป็นเหตุผล หลังสระใช้ -라서 (휴가라서) หลังพยัญชนะใช้ -이라서 (학생이라서)

การผัน

학생→ 학생이라서
주말→ 주말이라서
휴가→ 휴가라서
처음→ 처음이라서

เช่นเดียวกับ -아/어서 ไม่ตามด้วยคำสั่งหรือ “…กันเถอะ”: ✗ 주말이라서 같이 가요 → 주말이니까 같이 가요 이어서/여서 มีความหมายเหมือนกัน (학생이어서)

ตัวอย่าง

  • 오늘은 주말이라서 사람이 많아요.

    วันนี้เป็นวันหยุดสุดสัปดาห์ คนเลยเยอะ

  • 한국은 처음이라서 아직 잘 몰라요.

    มาเกาหลีครั้งแรก เลยยังไม่ค่อยรู้อะไร

เปรียบเทียบกับรูปแบบที่คล้ายกัน

-아/어서 เป็นรูปแบบเดียวกันสำหรับคำกริยาและคำคุณศัพท์ N이기 때문에 เป็นทางการกว่า ส่วน N이/가 아니라 หมายถึง “ไม่ใช่ N แต่…” (และ N이/가 아니라서 “เพราะไม่ใช่ N”)

รูปแบบที่เกี่ยวข้อง

  • -아/어서 เพราะ, จึง (เหตุผล); แล้ว (ลำดับเหตุการณ์)
  • -기 때문에 เพราะ (ว่า); N 때문에 = เพราะ N
  • N이/가 아니라 ไม่ใช่ N แต่ (เป็น N อีกอย่าง); ไม่ใช่ A แต่เป็น B
