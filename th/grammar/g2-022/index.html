ทำแบบทดสอบระดับ

เรียน › รูปแบบไวยากรณ์ภาษาเกาหลี › ระดับ 2

-는 중이다

อยู่ระหว่าง (ทำ); N 중 = ระหว่าง N, กำลัง N

ระดับ 2, TOPIK I · ระดับต้น

วิธีใช้

บอกว่ากำลังอยู่ระหว่างการกระทำหรือกระบวนการ ใช้บ่อยกับคำนาม: 회의 중, 수업 중, 공사 중, 통화 중

การผัน

공부하다→ 공부하는 중이에요
찾다→ 찾는 중이에요
만들다→ 만드는 중이에요
회의→ 회의 중이에요

ไม่ใช้กับคำคุณศัพท์: ✗ 바쁜 중이에요 → 바빠요 / 일하는 중이에요

ตัวอย่าง

  • 지금 집에 가는 중이에요. 조금만 기다려요.

    ตอนนี้กำลังกลับบ้านอยู่ รอแป๊บนึงนะ

  • 사장님은 지금 회의 중이세요.

    ท่านประธานบริษัทกำลังประชุมอยู่ตอนนี้

เปรียบเทียบกับรูปแบบที่คล้ายกัน

-고 있다 เป็นรูปกำลังกระทำทั่วไป (รวมถึงนิสัยและการสวมใส่) -는 중이다 เน้นว่ากำลังอยู่ระหว่างนั้นในตอนนี้ ส่วน -는 도중(에) บอกว่ามีบางอย่างเกิดขึ้นระหว่างการกระทำ

  • -고 있다 กำลัง (ทำ); กำลังสวมใส่
  • -는 동안 ระหว่างที่, ในช่วง (ช่วงเวลา); N 동안 = เป็นเวลา N / ระหว่าง N
  • -는 도중(에) ระหว่าง (ที่กำลังทำ), ระหว่างทาง
