รูปแบบไวยากรณ์ภาษาเกาหลี › ระดับ 2

-(으)ㄴ/는/(으)ㄹ 것 같다

ดูเหมือน, ท่าทางจะ; ฉันคิดว่า (การคาดเดาหรือความเห็นแบบนุ่มนวล)

ระดับ 2 · TOPIK I · ระดับต้น

วิธีใช้

แสดงการคาดเดาจากสิ่งที่เห็นหรือรู้ หรือทำให้ความเห็นของตนนุ่มนวลลง คำขยายแสดงเวลา: คำกริยา -(으)ㄴ (อดีต), -는 (ปัจจุบัน), -(으)ㄹ (อนาคต/คาดเดา) คำคุณศัพท์ -(으)ㄴ (ปัจจุบัน), -(으)ㄹ (คาดเดา)

การผัน

오다→ 온 것 같아요
오다→ 오는 것 같아요
오다→ 올 것 같아요
바쁘다→ 바쁜 것 같아요

คำคุณศัพท์ไม่ใช้ -는: ✗ 바쁘는 것 같아요 → 바쁜 것 같아요 คำผันไม่ปกติแบบ ㅂ: 춥다 → 추울 것 같아요

ตัวอย่าง

  • 하늘이 어두워요. 곧 비가 올 것 같아요.

    ท้องฟ้ามืดแล้ว ท่าทางฝนจะตกเร็ว ๆ นี้

  • 선생님이 오늘 좀 피곤하신 것 같아요.

    วันนี้คุณครูดูเหนื่อย ๆ นะ

เปรียบเทียบกับรูปแบบที่คล้ายกัน

-나 보다 เป็นการอนุมานจากหลักฐานและไม่ใช้กับประสบการณ์หรือความเห็นของตนเอง -(으)ㄴ/는 모양이다 เป็นการอนุมานจากร่องรอยแบบห่าง ๆ กว่า ส่วน -(으)ㄴ/는 듯하다 เป็นรูปภาษาเขียน

รูปแบบที่เกี่ยวข้อง

  • -나 보다 ดูเหมือนว่า, คงจะ (อนุมานจากสิ่งที่เห็น)
  • -(으)ㄴ/는 모양이다 ดูเหมือนว่า, ท่าทางจะ (อนุมานจากหลักฐาน)
  • -(으)ㄴ/는 듯하다 ดูเหมือน, คล้ายว่า (นุ่มนวลและเป็นภาษาเขียนมากกว่า -(으)ㄴ/는 것 같다)
