単語・会話

今日の単語、韓国ドラマのセリフ、日常フレーズ、そして韓国人がいま使うスラング。

すべて今日の単語ドラマの名セリフ日常フレーズスラング・新語敬語とタメ口
ドラマの名セリフ

韓国ドラマの別れのセリフ：잘 가から잘 지내まで

バス停、空港、そして最終回。韓国ドラマの登場人物が別れ際に使う9つのセリフを、日常的な잘 가から最後の잘 지내まで学び、実生活で使えるものも確認しましょう。

この記事のフレーズ: 잘 지내 = 元気でね／お元気で
日常フレーズ

韓国語のほめ言葉：ほめ方と返し方

잘했어요や멋있어요から부러워요まで、韓国人が毎日使うほめ言葉と、それに対する丁寧な返し方、아니에요、감사합니다、과찬이세요を学びましょう。

この記事のフレーズ: 과찬이세요 = お褒めにあずかり恐縮です（直訳：ほめすぎです）
スラング・新語

칼퇴、회식、불금：会社員なら誰でも知っている韓国の職場スラング

定時退社、会食、残業、そして金曜日の解放感。칼퇴や월급루팡から넵、퇴근각まで、韓国の会社員が使う職場の言葉とスラングを学びましょう。

この記事のフレーズ: 칼퇴 = 定時ぴったりに退社すること
今日の単語

눈치：空気を読む韓国の技

눈치とは、言われなくても人の気持ちを察する、目立たない技のことです。눈치가 빠르다、눈치가 없다、눈치 보다、눈치채다、눈치껏を、職場、学校、家庭での例とともに学びましょう。

この記事のフレーズ: 눈치 = 雰囲気を察すること、空気を読むこと
敬語とタメ口

해 줘から해 주실 수 있으세요?まで：韓国語のお願いの5段階

韓国語には、さっと言う해 줘からとてもやわらかい해 주실 수 있으세요?まで、助けを頼む言い方がはしごのように段階的にあります。5つの段階と、表現をやわらげる혹시、좀、죄송한데、そしてそれぞれが合う場面を学びましょう。

この記事のフレーズ: 해 주시겠어요? = （私のために）していただけますか？
今日の単語

가을 타다：「秋の物悲しさ」を表す韓国語

葉が落ち、夕方が早く暗くなると、韓国の人は가을 타다、直訳すると「秋に乗る」と言います。意味と使い方、そして仲間の表現추위를 타다と더위를 타다を学びましょう。

この記事のフレーズ: 가을 타다 = 秋にもの悲しくなる、秋に気分が沈む
ドラマの名セリフ

Kドラマの謝罪セリフ：미안해から우리 화해하자まで

Kドラマのカップルは必ずけんかをし、けんかは必ず謝罪で終わります。謝る、許しを求める、仲直りするための9つのセリフと、それぞれの文法を学びましょう。

この記事のフレーズ: 화 풀어 = もう怒らないで／機嫌直して
敬語とタメ口

씨、님、선배、언니：韓国語での人の呼び方

韓国語では「あなた」という言葉を避け、代わりに名前や肩書きを使います。민지 씨、팀장님、선배、언니をいつ使うのか、そしてうっかり失礼に聞こえてしまうのはどれなのかを学びましょう。

この記事のフレーズ: 씨 = 〜さん（名前の後につける丁寧な呼称）
日常フレーズ

電話の韓国語：여보세요から들어가세요まで

慣れない言語での電話は難しいものです。身ぶりも使えず、口の動きも読めません。韓国語で電話に出る、名乗る、聞き返す、伝言を残す、丁寧に電話を切る方法を学びましょう。

この記事のフレーズ: 여보세요 = もしもし（電話で）
スラング・新語

「너 T야?」：韓国の人のMBTIトーク

韓国では「MBTIは何？」は雑談の定番で、너 T야?はふざけたツッコミです。よく耳にするMBTIの言葉やミーム、そしてどんなときなら使っても大丈夫かを学びましょう。

この記事のフレーズ: 너 T야? = あなたTなの？（つまり、なんでそんなに共感してくれないの？）
今日の単語

화이팅：大事な日の前に韓国人が送る応援の言葉

11月の수능を前に、화이팅という言葉があちこちで聞こえてきます。意味やつづり、そして韓国語で「がんばって」と伝えるもっと温かい言い方を学びましょう。

この記事のフレーズ: 화이팅 = がんばって！／ファイト！
ドラマの名セリフ

韓国ドラマの告白セリフ：좋아해から우리 사귈래?まで

最初の좋아해から오늘부터 1일まで、ほぼすべての韓国ドラマの恋愛ストーリーで聞く8つのロマンスのセリフを、それぞれの文法と一緒に紹介します。

この記事のフレーズ: 우리 사귈래? = 付き合ってくれる？
敬語とタメ口

먹다、드시다、잡수시다：敬意を表すために変わる韓国語の単語

韓国語の動詞や名詞の中には、目上の人について話すときにまったく別の単語に変わるものがあります。먹다は드시다に、자다は주무시다に、집は댁に。大事な組み合わせを覚えましょう。

この記事のフレーズ: 드시다 = 召し上がる（食べる・飲むの尊敬語）
スラング・新語

ㄱㅅ、ㅊㅋ、ㄹㅇ：子音だけでできた韓国語のチャット略語

韓国人は初声の子音だけでメッセージを送ります。ㄱㅅはありがとう、ㅈㅅはごめん、ㅇㅈは同意。초성の略語のしくみと、誰に送っていいのかを学びましょう。

この記事のフレーズ: 초성 = 初声（音節の最初の子音）
日常フレーズ

友だちと韓国語で約束する：시간 돼?から그때 봐まで

友だちの都合を聞く、予定を提案する、時間と場所を決める、上手に断る。友だちと会うために必要な日常の韓国語を紹介します。

この記事のフレーズ: 시간 돼? = 時間ある？
ドラマの名セリフ

韓国ドラマに必ず出てくるセリフ10選

밥 먹었어?から정신 차려まで、ほぼすべての韓国ドラマに出てくる日常のセリフ10個を、ニュアンスや丁寧さのポイントと一緒に覚えましょう。

この記事のフレーズ: 밥 먹었어? = ごはん食べた？（タメ口）
今日の単語

괜찮아요：大丈夫、気にしないで、結構です、なかなかいい

ひとつの言葉に4つの役割。韓国人が괜찮아요を使って、大丈夫だと伝えたり、相手を許したり、丁寧に断ったり、控えめにほめたりする方法を学びましょう。

この記事のフレーズ: 괜찮아요 = 大丈夫です
敬語とタメ口

존댓말と반말：いつ、どうやって切り替える？

韓国人がいつ丁寧な言葉を使い、いつやめるのか。반말に切り替えようと提案する言い方や、そのときに変わる小さな言葉の違いを学びましょう。

この記事のフレーズ: 말 놓을까요? = タメ口で話しましょうか？
スラング・新語

2026年、ネットでよく見る韓国語スラング

ㅋㅋ、헐、갓생、킹받다など、コメント欄やチャットで出会う韓国のネットスラングを、意味とどのくらい失礼かと一緒に紹介します。

この記事のフレーズ: 신조어 = 新語、スラング
日常フレーズ

韓国のカフェで注文する：本当に使うフレーズ集

아이스 아메리카노 한 잔 주세요からテイクアウト、ショット追加、渡される呼び出しベルまで、韓国語で自信をもってコーヒーを注文しましょう。

この記事のフレーズ: 주세요 = ください
