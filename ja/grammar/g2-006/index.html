学ぶ › 韓国語の文法パターン › 2級

-(으)ㄴ/는/(으)ㄹ 것 같다

〜ようだ、〜みたいだ；〜と思う（推測・やわらかい意見）

2級, TOPIK I · 初級

使い方

見たり知ったりしたことに基づく推測を表したり、自分の意見をやわらげたりします。連体形が時を表します：動詞は -(으)ㄴ（過去）、-는（現在）、-(으)ㄹ（未来・推測）、形容詞は -(으)ㄴ（現在）、-(으)ㄹ（推測）です。

作り方

오다→ 온 것 같아요
오다→ 오는 것 같아요
오다→ 올 것 같아요
바쁘다→ 바쁜 것 같아요

形容詞に -는 は決してつきません：✗ 바쁘는 것 같아요 → 바쁜 것 같아요。ㅂ不規則活用：춥다 → 추울 것 같아요。

例文

  • 하늘이 어두워요. 곧 비가 올 것 같아요.

    空が暗いですね。もうすぐ雨が降りそうです。

  • 선생님이 오늘 좀 피곤하신 것 같아요.

    先生は今日少し疲れているようです。

似た表現との違い

-나 보다 は根拠からの推論で、自分の経験や意見には使いません。-(으)ㄴ/는 모양이다 は兆候からの、より客観的な推論です。-(으)ㄴ/는 듯하다 は書き言葉での同等表現です。

音声とクイズで練習しよう

Pocket Koreanなら、すべての例文にネイティブ音声付き。間隔反復の復習やTOPIK模試もできます。

関連する表現

  • -나 보다 〜みたいだ、〜らしい（見たことからの推論）
  • -(으)ㄴ/는 모양이다 〜ようだ、〜らしい（根拠に基づく推測）
  • -(으)ㄴ/는 듯하다 〜ようだ、〜らしい（-(으)ㄴ/는 것 같다 より柔らかく書き言葉的）
