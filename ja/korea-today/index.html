今日の韓国

韓国でいま話題のこと——韓国ドラマ、K-pop、カルチャー、トレンド。どの記事にも韓国語フレーズ付き。

すべて韓国ドラマ・映画K-popカルチャートレンド
K-pop

新人A2O LITE、「NEON」で3日連続の音楽番組1位

イ・スマンが手がける9人組の新ガールズグループが、Melonで史上最速級の1位を獲得した1週間後、『THE SHOW』『SHOW CHAMPION』『M COUNTDOWN』でトロフィーを手にしました。ニュースの内容と、韓国語で「1位」の言い方を紹介します。

この記事のフレーズ: 1위 = 1位、ナンバーワン
韓国ドラマ・映画

『Between Steps』、折り返し地点で自己最高視聴率を更新

チュ・ヨンウとキム・ソヒョン主演、ロボット工学研究室を舞台にしたENAのロマンスドラマが第6話で自己最高視聴率を記録しました。ニュースの内容と、韓国語タイトル「연애박사」の意味を紹介します。

この記事のフレーズ: 연애박사 = 恋愛の達人（直訳は「恋愛博士」）
カルチャー

韓食の日：韓国に初めて韓国料理の公式記念日が誕生

10月24日は、韓国料理のための新しい国の記念日「韓食の日」の初めての日です。国立中央博物館での記念式典と、日曜日まで続く3日間の「韓食大祝祭」で幕を開けました。

この記事のフレーズ: 한식 = 韓国料理、韓食
トレンド

探鳥（탐조）：韓国の若者がバードウォッチングを始める理由

かつては大きなカメラを持った中年男性の趣味と見られていたバードウォッチングが、韓国のミレニアル世代やZ世代のおしゃれな趣味になりつつあります。多くはスマホ1台で、マンションの団地や街の公園で楽しんでいます。

この記事のフレーズ: 탐조 = バードウォッチング、探鳥
トレンド

レモン、ミント、パープル：韓国の冬のダウンがカラフルに

黒いダウンジャケットは長年韓国の冬の定番でしたが、今シーズンはパープル、レモン、ミントを検索する人が増えています。データが示す傾向と、패딩を買うときに必要な韓国語を紹介します。

この記事のフレーズ: 패딩 = ダウンジャケット、中綿入りのコート
カルチャー

韓服文化週間：韓服を着ればお得に入場

第9回韓服文化週間が10月25日まで、国内外410か所以上で開かれています。国立中央博物館での韓服の日のショーや、韓服を着た人向けの割引を紹介します。

この記事のフレーズ: 한복 = 韓服、韓国の伝統衣装
K-pop

NCT WISH「I SPY」、発売初日に120万枚を売り上げ

NCT WISHの4thミニアルバム「I SPY」がハントチャートで初週155万枚以上を売り上げ、2つの週間チャートで1位になりました。数字が意味することと、ファンなら誰もが使うKポップ用語を紹介します。

この記事のフレーズ: 초동 = アルバムの初週売上
韓国ドラマ・映画

『Take Charge of My Heart』がけん引、Kドラマがネットフリックス非英語チャートを席巻

キム・ヨングァンとチェ・スビンの電撃ラブコメが世界2位にランクインし、非英語作品で最も長い視聴時間を記録しました。ネットフリックスのトップ4のうち3作がKドラマです。ドラマの内容とタイトルの韓国語を紹介します。

この記事のフレーズ: 충전 = （バッテリーの）充電
トレンド

フェクニック：ソウルの若者が刺身を漢江に持っていく理由

漢江でフライドチキンにライバルが登場。韓国の若者が鷺梁津市場で刺身を買い、川辺のピクニックにする「フェクニック」というトレンドを紹介します。

この記事のフレーズ: 회크닉 = 刺身ピクニック（회＋ピクニック）
韓国ドラマ・映画

「Love in Disguise」がtvNで同時間帯1位のスタート

イム・シワンとソル・イナ主演のロマンススリラーが10月19日に5.6%で初回を迎え、第2話でも同時間帯のケーブルチャンネル1位を守りました。あらすじとタイトルの韓国語を紹介します。

この記事のフレーズ: 유죄 = 有罪（判決として）
K-pop

NMIXX「Birthday Wish」がMelonで5位に上昇

NMIXXの6枚目のミニアルバム「Strange Muse」が10月19日にリリースされ、タイトル曲「긴 소원 (Birthday Wish)」は数時間でMelon Top 100のトップ5入りを果たしました。

この記事のフレーズ: 소원 = 願い
カルチャー

城北アートウィーク、ソウルの古い家がギャラリーに

第1回城北アートウィークが2026年11月1日まで開催中です。11か所の歴史的な家屋や史跡で現代アートが展示され、ソ・セオクとス・ドホの父子展も開かれています。

この記事のフレーズ: 집 = 家、わが家
韓国ドラマ・映画

『100 Days of Deception』、視聴率2桁目前に

キム・ユジョンとパク・ジニョン主演のtvN時代劇スパイドラマが、最初の2週末で5.3%から9.0%に上昇。どんな物語なのかを紹介します。

この記事のフレーズ: 첫 방송 = 初回放送
韓国ドラマ・映画

キム・ジウォン主演の韓国版『ドクターX』、視聴率20%に迫る

キム・ジウォン主演のSBS医療ドラマ『ドクターX』が第4話で18.5%を記録。これまでのあらすじと、ドラマに出てくる韓国語を紹介します。

この記事のフレーズ: 시청률 = 視聴率

K-pop

SEVENTEENのジョンハンとジョシュアがユニット「JxJ」として『DREAMSCAPE』でデビュー

SEVENTEENのジョンハンとジョシュアが10月19日、ユニット初のミニアルバム『DREAMSCAPE』をリリース。タイトル曲はディスコ風味の「12 o'clock」です。

この記事のフレーズ: 꿈 = 夢
トレンド

「ヒョンベクコア」とは？ 韓国の若者が夢中のデパート系ファッション

「ヒョンベクコア」という新しいスタイル名が韓国のSNSで広がっています。その意味と、背景にある韓国語のスラングを紹介します。

この記事のフレーズ: 현백 코어 = 現代百貨店コア（さりげないお金持ちスタイル）

カルチャー

ハングルの日が100周年　光化門でお祝いのフェスティバル

2026年10月9日、韓国はハングルの日100周年を迎えました。光化門広場ではメディアファサードのショーや正しいつづりを当てるゲーム、書道体験が行われました。

この記事のフレーズ: 한글날 = ハングルの日（10月9日）
K-pop

IVE、ILLIT、RIIZEが激突！ 混戦の10月カムバック競争

2026年10月はK-POPの新作ラッシュ。最大の山場は10月26日で、IVE、ILLIT、RIIZEがそろって新曲をリリースします。今月のカレンダーをまとめました。

この記事のフレーズ: 컴백 = カムバック、新作リリース
