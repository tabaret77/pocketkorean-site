1時間でハングルが読める：24の文字と音節のしくみ

2026-10-21

この記事のフレーズ: 한글 = ハングル（韓国語の文字）単語を検索

韓国語は最初、小さな四角がずらっと並んだ壁のように見えます。でもその四角は、少ない数の文字からできています。한글（hangeul）＝ハングルは、覚えやすいように作られた文字です。世宗大王のもとで作られ、1446年に훈민정음（Hunminjeongeum／訓民正音）、「民を教える正しい音」として公布されました。1時間あれば、看板やメニューを声に出して読めるようになりますよ。

基本の子音14個

子音のいくつかは、口の形をそのまま絵にしたものです。ㄱは舌の奥が上あごにつく形、ㄴは舌先が歯の裏につく形、ㅁは閉じた唇の形を表しています。画を加えると、息を強く出す音になります：ㄱ → ㅋ、ㄷ → ㅌ、ㅂ → ㅍ、ㅈ → ㅊ。

文字 音 文字 音
ㄱ g / k（ガ行／カ行） ㅇ 最初では無音、最後ではng
ㄴ n（ナ行） ㅈ j（ジャ行）
ㄷ d / t（ダ行／タ行） ㅊ ch（チャ行）
ㄹ r / l（ラ行） ㅋ k（息を強く出す）
ㅁ m（マ行） ㅌ t（息を強く出す）
ㅂ b / p（バ行／パ行） ㅍ p（息を強く出す）
ㅅ s（サ行） ㅎ h（ハ行）

平音のㄱ、ㄷ、ㅂ、ㅈは、「g／k」「d／t」「b／p」「j／ch」の中間の音です。単語の最初ではk、t、p、chに近く聞こえ、母音にはさまれるとg、d、b、jにやわらかくなります。そのため김치（gimchi）＝キムチは、公式のローマ字表記ではgで書きますが、耳には「キムチ」と聞こえるのです。

基本の母音10個

母音は3つの要素からできています。点または短い画（天）、横線ㅡ（地）、縦線ㅣ（人）です。短い画をもう1本加えると、「y」の音がつきます。

母音 音 母音 音
ㅏ a（「ア」） ㅗ o（唇を丸めた「オ」）
ㅑ ya（「ヤ」） ㅛ yo（「ヨ」）
ㅓ eo（口を大きく開けた「オ」） ㅜ u（唇を丸めて突き出す「ウ」）
ㅕ yeo（口を大きく開けた「ヨ」） ㅠ yu（「ユ」）
ㅣ i（「イ」） ㅡ eu（唇を横に引いた「ウ」）

これで24文字です。ほかに濃音（ㄲ、ㄸ、ㅃ、ㅆ、ㅉ）が5つと、ㅐ（ae）、ㅔ（e）、ㅘ（wa）のような合成母音が11個ありますが、どれも基本の文字の組み合わせなので、あとから簡単に覚えられます。

音節のブロックを作る

韓国語は、英語のように文字を横一列に並べて書くのではなく、1つの音節を1つのブロックにまとめて書きます。どのブロックにも少なくとも子音と母音が1つずつあり、母音の形によって置く場所が決まります。

1. 縦長の母音（ㅏ ㅑ ㅓ ㅕ ㅣ）は子音の右に置きます。

  • ㄴ + ㅏ = 나（na）
  • ㅁ + ㅓ = 머（meo）

2. 横長の母音（ㅗ ㅛ ㅜ ㅠ ㅡ）は子音の下に置きます。

  • ㄱ + ㅗ = 고（go）
  • ㄴ + ㅜ = 누（nu）

3. 母音で始まる音節は、無音のㅇを場所取りに使います。

  • ㅇ + ㅏ = 아（a）
  • ㅇ + ㅜ = 우（u）

母音はブロックの中で単独では立てないので、ㅇが空いた子音の席を埋めるのです。

4. 最後の子音はいちばん下に置きます。 この下の子音を받침（batchim／パッチム）、「支え」と呼びます。

  • ㅎ + ㅏ + ㄴ = 한（han）
  • ㄱ + ㅜ + ㄱ = 국（guk）
  • 한 + 국 = 한국（Hanguk）＝韓国

ブロックの下にあるㅇは「ng」と発音します：강（gang）＝川。

読む練習

ローマ字を隠して読んでみましょう。どれも基本の24文字だけでできています。

韓国語 ローマ字 意味
나무 namu 木
바다 bada 海
우유 uyu 牛乳
서울 Seoul ソウル
사랑 sarang 愛
친구 chingu 友だち
라면 ramyeon インスタントラーメン
한국어 hangugeo 韓国語

한국어では、어が無音のㅇで始まるので、국の最後のㄱが次の音節に移り、「han-gu-geo（ハングゴ）」と発音することに注目してください。韓国語では、最後の子音が母音と出会うといつもこうなり、話し言葉がなめらかにつながります。

最初の1時間のコツ

  • 母音から覚える。 たった10個で、どのブロックでも骨組みになります。
  • 文字だけでなく、実際の単語を読む。 お店の看板、地下鉄の駅名、K-POPの曲名は最高の練習材料です。
  • ブロックを1つずつ手で書く。 書き順は基本的に上から下、左から右です。
  • ローマ字にいつまでも頼らない。 ローマ字は松葉づえのようなもので、特にㅓとㅡなど、本当の音を隠してしまうことがあります。

이거 어떻게 읽어요? igeo eotteoke ilgeoyo? これはどう読みますか？

ブロックのしくみがわかれば、出会う韓国語の単語はすべて声に出して読めるものになります。それこそが、韓国語学習の本当のスタートです。
