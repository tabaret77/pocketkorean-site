ハングルの基礎

ㅐ、ㅘ、ㅢ：ハングルの11の複合母音

ハングルの11の複合母音が基本母音からどう作られているか、なぜ現代のソウル方言でㅐとㅔが同じ音になるのか、そして의사、희망、우리의に見るㅢの3つの読み方を解説します。

この記事のフレーズ: 모음 = 母音
文法

-(으)ㄹ 거예요：韓国語で予定と推測を話す

-(으)ㄹ 거예요で「これから何をするか」を言う方法。パッチムのルール、갈 거예요に隠れたㄲの音、変則動詞、추울 거예요のような推測、そして-(으)ㄹ게요との違いを解説します。

この記事のフレーズ: 갈 거예요 = （私は）行きます、行くつもりです
テーマ別単語

韓国語の家族の呼び方：엄마、할머니、이모、そして誰が何と言うか

韓国語の家族の呼び方は、話す人が誰か、父方か母方かによって変わります。엄마と어머니の違い、형、누나、동생、친가と외가、そして自分の家族の話し方を学びましょう。

この記事のフレーズ: 가족 = 家族
TOPIKガイド

TOPIK IIの聞き取り：巻き戻せない50問への対処法

TOPIK IIの聞き取り試験のための実践的なプラン。50問の構成、音声が1回流れる問題と2回流れる問題、問題の合間に先読みする方法、そして3週間の練習プランを紹介します。

この記事のフレーズ: 듣기 = 聞き取り（試験の科目）
テーマ別単語

趣味の韓国語：好きなことについて話す方法

등산や독서から뜨개질や게임まで：趣味を表す韓国語24語と、취미가 뭐예요?の聞き方、そして-기と-는 것을 좋아해요を使った答え方を紹介します。

この記事のフレーズ: 취미가 뭐예요? = 趣味は何ですか？
文法

-았어요/었어요：韓国語で過去のことを話す

-았어요/었어요/했어요を使った丁寧な過去形の作り方：母音のルール、갔어요や마셨어요のような縮約、名詞、不規則動詞、そして否定形を学びましょう。

この記事のフレーズ: 했어요 = （わたしは）しました
ハングルの基礎

ㄱ、ㅋ、それともㄲ？ 平音・激音・濃音

달、탈、딸がなぜ3つの別々の単語なのか：韓国語の平音・激音・濃音の聞き分け方と発音のしかたを、ティッシュを使ったテスト、単語のセット、ローマ字表記のヒントとともに紹介します。

この記事のフレーズ: 된소리 = 濃音（直訳は「硬い音」）
TOPIKガイド

TOPIK IIの読解：70分で50問を解き切る方法

TOPIK II読解セクションのための実践的なプラン：問題用紙の3つのパートの特徴、70分の配分のしかた、そして各問題タイプを解く鍵になる韓国語を紹介します。

この記事のフレーズ: 지문 = （試験の）問題文、読解文
ハングルの基礎

パッチムをやさしく：韓国語の7つの終声

옷、낮、꽃がすべて同じ音で終わるのはなぜ？終声（받침）がとる7つの音、二重パッチム、そして終声が次の母音につながるしくみを学びましょう。

この記事のフレーズ: 받침 = パッチム、終声（音節のいちばん下にある子音）
文法

-고 싶다：韓国語で「〜したい」と言う方法

-고 싶다を使って、したいことを言えるようになりましょう。活用表、否定形と過去形、「会いたい」、そしてほかの人について話す-고 싶어하다の形も紹介します。

この記事のフレーズ: 보고 싶어요 = 会いたいです／見たいです
テーマ別単語

キムジャンの単語：キムチ作りの季節の韓国語

白菜や唐辛子粉から、塩漬けや和えるところまで。晩秋のキムチ作りの季節、김장にまつわる韓国語24語と、すぐ使えるフレーズを紹介します。

この記事のフレーズ: 김장 = 冬に備えたキムチ作り（キムジャン）
TOPIKガイド

TOPIK II 作文の問題54：長文エッセイをステップごとに攻略

TOPIK IIの作文で出る600〜700字のエッセイがどう採点されるか、25分でどう構成するか、そして自然に見える書き言葉の韓国語を紹介します。

この記事のフレーズ: 주장 = 主張、意見
文法

-아요/어요：毎日使う丁寧な語尾

-아요/어요の語尾を、基本のルールから가요や해요のような縮約形まで、例文とミニ練習問題でステップごとに学びましょう。

この記事のフレーズ: 해요 = します（하다の丁寧な現在形）
ハングルの基礎

1時間でハングルが読める：24の文字と音節のしくみ

韓国語の文字の子音14個と母音10個、そしてそれらを組み合わせて音節のブロックを作る方法を覚えて、今日から読み始めましょう。

この記事のフレーズ: 한글 = ハングル（韓国語の文字）

韓国語の試験TOPIKのしくみ、各級に必要な点数、そして2026年10月時点で確定している今後の試験日を紹介します。

この記事のフレーズ: 한국어능력시험 = 韓国語能力試験（TOPIK）

韓国語の天気の単語

晴れ、雨、雪、PM2.5、梅雨について韓国語で話してみましょう。日常でよく使う天気の単語26個と例文を紹介します。
