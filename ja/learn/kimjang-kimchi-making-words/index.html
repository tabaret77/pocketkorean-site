キムジャンの単語：キムチ作りの季節の韓国語

2026-10-22

この記事のフレーズ: 김장 = 冬に備えたキムチ作り（キムジャン）単語を検索

韓国で空気が冷たくなると、市場には白菜の山と赤い唐辛子粉の袋があふれます。김장（gimjang）、キムジャンの季節です。家族やご近所が集まって、冬じゅう食べられるだけの大量のキムチを作る時期です。この伝統は韓国の暮らしにとても深く根づいていて、ユネスコは2013年に「キムジャン：大韓民国におけるキムチの製造と分配」を無形文化遺産に登録しました。キムジャンに参加するために必要な語彙を紹介します。

キムジャンの流れ

一般的なキムジャンの日は同じ手順で進み、それぞれの手順に専用の動詞があります。

  1. 절이다（jeorida）＝塩漬けにする。半分に切った白菜を塩水に浸けたり塩を振ったりして、しんなりさせます。今では多くの家庭が、1日分の作業を省くために、塩漬け済みの白菜절임배추（jeorimbaechu）を買っています。
  2. 씻다（ssitda）＝洗う。塩漬けにした白菜をすすいで水を切ります。
  3. 양념을 만들다（yangnyeomeul mandeulda）＝ヤンニョム（合わせ調味料）を作る：唐辛子粉、にんにく、しょうが、魚醤、千切りの大根、ねぎ。
  4. 버무리다（beomurida）＝和える、まぶす。みんなでゴム手袋をはめて大きなたらいを囲んで座り、赤い具を葉の1枚1枚の間に塗り込みます。
  5. 담그다（damgeuda）＝（キムチや漬物を）漬ける。できあがったキムチを容器に入れ、多くの場合は専用のキムチ冷蔵庫にしまいます。

そしていちばん楽しい時間がやってきます。ゆでた豚肉を、漬けたばかりの新鮮なキムチで包んで食べ、親戚やご近所に箱で送るのです。

発音に注意

いくつかの単語は、つづりどおりには発音しません。

  • 고춧가루は[고추까루]と発音します。真ん中のㅅによってㄱが濃音になります：「ゴチュッカル」。
  • 젓갈は[젇깔]と発音します。終声のㅅはtのように聞こえ、その後のㄱが濃音になります：「ジョッカル」。
  • 익다は[익따]（ikda）と発音し、익었어요（igeosseoyo）＝熟しました、ではㄱが次の音節につながります。

味を表す言葉

キムジャンは、誰もが味について一家言を持つ時でもあります。こんな言葉が聞こえてきます。

  • 맵다（maepda）＝辛い → 좀 매워요（jom maewoyo）＝ちょっと辛いです
  • 짜다（jjada）＝しょっぱい → 너무 짜요（neomu jjayo）＝しょっぱすぎます
  • 싱겁다（singgeopda）＝味が薄い、塩気が足りない → 좀 싱거워요（jom singgeowoyo）
  • 맛있다（masitda）＝おいしい → 진짜 맛있어요!（jinjja masisseoyo!）

맵다と싱겁다はㅂ不規則動詞なので、ㅂが우に変わります：매워요、싱거워요。

キムジャンの席で使えるフレーズ

  • 저도 도와드릴게요.（Jeodo dowadeurilgeyo.）＝わたしもお手伝いします。
  • 간 좀 봐 주세요.（Gan jom bwa juseyo.）＝味見をしてください。
  • 김치 좀 나눠 드릴게요.（Gimchi jom nanwo deurilgeyo.）＝キムチを少しおすそ分けしますね。

韓国の友だちやご近所さんからキムジャンに誘われたら、ぜひ参加しましょう。大変な作業ですが、韓国の1年の中でもいちばん心温まる体験のひとつです。
