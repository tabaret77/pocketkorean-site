ㄱ、ㅋ 還是 ㄲ？平音、激音和緊音

2026-10-23

本篇韓文句子: 된소리 = 緊音（字面意思是「硬的聲音」）查單字

달（dal）是月亮，탈（tal）是面具，딸（ttal）是女兒。對初學者的耳朵來說，前兩個字可能聽起來差不多，第三個也許完全聽不出差別。但對韓國人來說，這是三個完全不同的字。韓語把許多子音分成三個一組：平音、激音 和 緊音。一旦你能聽出、也能發出其中的差別，很多「為什麼他們聽不懂我？」的時刻就會消失。

五個家族

平音（예사소리） 激音（거센소리） 緊音（된소리）
ㄱ g/k ㅋ k ㄲ kk
ㄷ d/t ㅌ t ㄸ tt
ㅂ b/p ㅍ p ㅃ pp
ㅈ j ㅊ ch ㅉ jj
ㅅ s – ㅆ ss

看看字形：韓文字母本身就顯示了家族關係。多加一筆就是激音（ㄱ → ㅋ、ㄷ → ㅌ、ㅈ → ㅊ），把字母重複一次就是緊音（ㄱ → ㄲ）。ㅅ 沒有對應的激音，只有緊音 ㅆ。

每個音怎麼發

平音：輕輕帶一點氣。 예사소리（yesasori）是放鬆的音。在字首時會帶一點點氣，介於注音的「ㄍ」和「ㄎ」之間。在母音之間會變得更柔和、帶有聲帶振動：아기（agi）——嬰兒——裡的 ㄱ，聽起來就像英文真正的「g」。

激音：強烈送氣。 거센소리（geosensori），「粗重的聲音」，會伴隨一大股氣流，比注音「ㄎ」那樣的送氣音還要強。試試面紙測試：在嘴巴前面拿一張面紙，說 탈（tal）。面紙應該會飄起來。

緊音：不送氣，喉嚨繃緊。 된소리（doensori），「硬的聲音」，幾乎完全不送氣。把喉嚨繃緊，就像準備要舉起很重的東西一樣，然後俐落地把音放出來。說 딸（ttal）的時候，面紙應該幾乎不動。緊音也會讓後面的母音聽起來音高稍微高一點。

一個好用的練習方法，是拿著面紙，慢慢地連續說這三個字：달 – 탈 – 딸。一點點氣、很多氣、沒有氣。

練習用的單字組

平音 激音 緊音
불 (bul)——火 풀 (pul)——草、膠水 뿔 (ppul)——角
달 (dal)——月亮 탈 (tal)——面具 딸 (ttal)——女兒
자다 (jada)——睡覺 차다 (chada)——踢；冰冷 짜다 (jjada)——鹹
개 (gae)——狗 – 깨 (kkae)——芝麻
기 (gi)——氣、能量 키 (ki)——身高 –
사다 (sada)——買 – 싸다 (ssada)——便宜

最後一組是購物時經典的混淆：사요（sayo）是「我要買」，而 싸요（ssayo）是「很便宜」。

萬聖節就快到了，탈 是個值得記住的字。它是韓國傳統面具的名稱，例如 하회탈（hahoetal，河回面具），一種有名的木雕面具風格。

隱藏的緊音

有時候字面上寫的是平音，卻要唸成緊音。這會發生在收尾音 ㄱ、ㄷ 或 ㅂ 的後面：

  • 학교（hakkyo [학꾜]）——學校 → [학꾜]
  • 식당（siktang [식땅]）——餐廳 → [식땅]
  • 입구（ipku [입꾸]）——入口 → [입꾸]

韓語的國語羅馬字標記法（Revised Romanization）不會標出字中間的緊音化，所以你看到的是「hakgyo」，實際上卻要唸得比較接近「hak-kyo」。拼寫維持平音，改變的只有發音。

羅馬拼音小技巧

在羅馬拼音中，重複的字母就是緊音：kk、tt、pp、jj、ss。在音節開頭的單一字母 k、t、p、ch 是激音，而 g、d、b、j 是平音。所以 꼬리（kkori）——尾巴——是緊音，코（ko）——鼻子——是激音，고기（gogi）——肉——則是平音。

實用韓語

韓語 羅馬拼音 意思
예사소리 yesasori 平音
거센소리 geosensori 激音（送氣音）
된소리 doensori 緊音
달 / 탈 / 딸 dal / tal / ttal 月亮／面具／女兒
불 / 풀 / 뿔 bul / pul / ppul 火／草／角
사요 / 싸요 sayo / ssayo 我要買／很便宜
다시 말해 주세요 dasi malhae juseyo 請再說一次

이거 ㄲ이에요, ㅋ이에요?（Igeo ssanggiyeogieyo, kieugieyo?）——這是 ㄲ 還是 ㅋ？不確定自己聽到什麼時，可以這樣問韓國朋友；像 ㄲ 叫做 쌍기역（ssanggiyeok）、ㅋ 叫做 키읔（kieuk）這樣的字母名稱，也很值得學起來。
