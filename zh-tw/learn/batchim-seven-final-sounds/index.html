收尾音一次搞懂：韓語的7個代表音

2026-10-22

本篇韓文句子: 받침 = 收尾子音（寫在音節下方）查單字

大聲唸出 옷（ot）——衣服——和 꽃（kkot）——花，你會發現它們都以同樣的「t」音結尾，雖然一個寫成 ㅅ，另一個寫成 ㅊ。這不是寫錯了。韓語有很多字母可以放在音節方塊的下方，但當一個字在那裡結束時，它們只會歸結為 七種音。學會這七種音，韓語拼寫的一大層規則就會突然變得合理。

什麼是收尾音

받침（batchim）是寫在音節方塊下方的子音，例如 한（han）或 국（guk）。在音節開頭時，子音是「放開的」——你會把氣送出來。在結尾時，韓語不會把它放開：舌頭或嘴唇閉上、停住就好。收尾的 ㄱ 聽起來就像台語「六」（la̍k）結尾的 k，只擺好口型、不把氣送出來。因為沒有放開的動作，像 ㅅ、ㅈ、ㅊ 之間的差別也就消失了。

七個代表音

每個收尾音都會唸成以下七種之一：ㄱ、ㄴ、ㄷ、ㄹ、ㅁ、ㅂ、ㅇ。

收尾音 會發這個音的字母 例子 實際唸法
ㄱ [k] ㄱ、ㅋ、ㄲ 부엌 (bueok)——廚房 [부억]
ㄴ [n] ㄴ 산 (san)——山 [산]
ㄷ [t] ㄷ、ㅌ、ㅅ、ㅆ、ㅈ、ㅊ、ㅎ 꽃 (kkot)——花 [꼳]
ㄹ [l] ㄹ 물 (mul)——水 [물]
ㅁ [m] ㅁ 밤 (bam)——夜晚、栗子 [밤]
ㅂ [p] ㅂ、ㅍ 앞 (ap)——前面 [압]
ㅇ [ng] ㅇ 강 (gang)——江、河 [강]

最大的一組是 ㄷ 這一列：七個不同的字母都以同樣短促的「t」結尾。這就是為什麼 옷（ot）、낮（nat）——白天——和 꽃（kkot）會押韻，也是為什麼單獨唸的時候，낮（白天）和 낫（鐮刀）聽起來一模一樣。同樣地，밖（bak）——外面——聽起來就跟 박（bak）一樣。

官方羅馬拼音是依照發音而不是字母來寫，所以收尾的 ㄱ／ㄷ／ㅂ 組分別寫成 k、t、p：부엌 是「bueok」，꽃 是「kkot」，앞 是「ap」。

雙收尾音

有些音節下方有兩個子音，例如 닭 或 값。單獨唸的時候，只唸其中一個——通常是第一個：

  • 값（gap）——價格 → [갑]
  • 앉다（anda）——坐 → [안따]
  • 없다（eopda）——沒有 → [업따]

有少數常見的則改唸第二個字母，尤其是 ㄺ 和 ㄻ：

  • 닭（dak）——雞 → [닥]
  • 읽다（ikda）——讀 → [익따]
  • 삶（sam）——人生 → [삼]

不要想一次背下所有的組合；每學一個單字，就連同它的發音一起記。

後面接母音時：字母會回來

重點來了。當下一個音節以母音開頭（也就是以不發音的 ㅇ 開頭）時，收尾音就不再卡在結尾。它會移過去，用它 原本 的音來唸。這種連音叫做 연음（yeoneum，連音）。

  • 옷 唸 [옫]，但 옷이（osi）→ [오시]——ㅅ 回來了
  • 꽃 唸 [꼳]，但 꽃을（kkocheul）→ [꼬츨]——ㅊ 回來了
  • 부엌 唸 [부억]，但 부엌에（bueoke）→ [부어케]
  • 닭 唸 [닥]，但 닭이（dalgi）→ [달기]——兩個字母都聽得到
  • 값 唸 [갑]，但 값이（gapssi）→ [갑씨]

這就是為什麼拼寫會保留「真正的」字母：只要加上助詞或語尾，它就會出現。（ㅎ 是例外：它通常會變得不發音，例如 좋아요 [조아요]。）

快速練習

唸唸看每個字，再對照括號裡的發音。

  1. 밭（田）→ [받]
  2. 있다（在、有）→ [읻따]
  3. 숲（森林）→ [숩]
  4. 꽃이（花 + 主格助詞）→ [꼬치]
  5. 앞에（在前面）→ [아페]
  6. 흙（土）→ [흑]

實用韓語

韓語 羅馬拼音 意思

발음 bareum 發音
연음 yeoneum 連音（把收尾子音連到下一個母音）
옷 / 옷이 ot / osi 衣服／衣服（主格）
꽃 / 꽃을 kkot / kkocheul 花／花（受格）
닭 / 닭이 dak / dalgi 雞／雞（主格）
값 gap 價格
발음이 어려워요 bareumi eoryeowoyo 發音很難

꽃은 [꼳]으로 발음해요.（Kkocheun [kkot]-euro bareumhaeyo.）——꽃 唸作「kkot」。用「___은/는 ___로 발음해요」這個句型，請老師或朋友幫你確認收尾音唸得對不對。
