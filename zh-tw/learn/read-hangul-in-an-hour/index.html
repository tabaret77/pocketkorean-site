學習 › 韓文字母入門

一小時學會讀韓文：24個字母和音節的組合方式

2026-10-21

本篇韓文句子: 한글 = 韓文字母查單字

韓文乍看之下像一堵由小方塊砌成的牆，但這些方塊其實是由一小組字母組成的。한글（hangeul）——韓文字母——本來就是為了好學而設計的。它是在世宗大王主導下創制，並於1446年以 훈민정음（Hunminjeongeum）「訓民正音」之名頒布，意思是「教導百姓的正確字音」。給它一小時，你就能開始拼讀招牌和菜單了。

14個基本子音

有好幾個子音的形狀，就是嘴巴的簡單圖像：ㄱ 是舌根碰到上顎的樣子，ㄴ 是舌尖碰到牙齒後方，ㅁ 是閉起來的嘴唇。多加一筆就代表多送一口氣：ㄱ → ㅋ、ㄷ → ㅌ、ㅂ → ㅍ、ㅈ → ㅊ。

字母 發音 字母 發音
ㄱ g / k ㅇ 在開頭不發音，在結尾唸 ng
ㄴ n ㅈ j
ㄷ d / t ㅊ ch
ㄹ r / l ㅋ k（送氣）
ㅁ m ㅌ t（送氣）
ㅂ b / p ㅍ p（送氣）
ㅅ s ㅎ h

平音 ㄱ、ㄷ、ㅂ、ㅈ 的發音介於「g/k」、「d/t」、「b/p」、「j/ch」之間，跟注音的ㄍ、ㄉ、ㄅ、ㄐ這類不送氣音很接近；而送氣的 ㅋ、ㅌ、ㅍ、ㅊ 則接近ㄎ、ㄊ、ㄆ、ㄑ。平音在字首時聽起來比較接近 k、t、p、ch；夾在母音之間時，則會軟化成 g、d、b、j。這就是為什麼 김치（gimchi）——泡菜——在官方羅馬拼音裡寫成 g，聽起來卻像「kimchi」。

10個基本母音

母音是由三個概念構成的：一個點或短筆畫（天）、一條橫線 ㅡ（地）和一條直線 ㅣ（人）。再多加一個短筆畫，就會多一個「y」的音。

母音 發音 母音 發音
ㅏ a（像「啊」） ㅗ o（嘴唇圓圓的「喔」）
ㅑ ya ㅛ yo
ㅓ eo（嘴巴張開、不圓唇的「喔」） ㅜ u（像「嗚」）
ㅕ yeo ㅠ yu
ㅣ i（像「衣」） ㅡ eu（嘴角往兩邊拉、不圓唇的「ㄜ」）

這樣就是24個字母了。另外還有五個雙子音（ㄲ、ㄸ、ㅃ、ㅆ、ㅉ）和十一個複合母音，像是 ㅐ（ae）、ㅔ（e）和 ㅘ（wa），但它們都是由基本字母組成的，之後學起來會很輕鬆。

組成音節方塊

韓文不像英文那樣把字母排成一行，而是每個音節組成一個方塊，有點像中文的方塊字。每個方塊至少有一個子音和一個母音，而母音的形狀決定它要放在哪裡。

1. 直的母音（ㅏ ㅑ ㅓ ㅕ ㅣ）放在子音右邊。

  • ㄴ + ㅏ = 나（na）
  • ㅁ + ㅓ = 머（meo）

2. 扁的母音（ㅗ ㅛ ㅜ ㅠ ㅡ）放在子音下面。

  • ㄱ + ㅗ = 고（go）
  • ㄴ + ㅜ = 누（nu）

3. 以母音開頭的音節，要用不發音的 ㅇ 來佔位。

  • ㅇ + ㅏ = 아（a）
  • ㅇ + ㅜ = 우（u）

母音不能單獨組成一個方塊，所以要用 ㅇ 填補空著的子音位置。

4. 結尾的子音放在最下面。 這個底下的子音叫做 받침（batchim），意思是「支撐」，也就是「收尾音」。

  • ㅎ + ㅏ + ㄴ = 한（han）
  • ㄱ + ㅜ + ㄱ = 국（guk）
  • 한 + 국 = 한국（Hanguk）——韓國

ㅇ 在方塊底部時唸「ng」：강（gang）——江、河。

練習讀讀看

把羅馬拼音遮起來，試著讀讀看。這些詞只用到24個基本字母：

韓語 羅馬拼音 意思
나무 namu 樹
바다 bada 海
우유 uyu 牛奶
서울 Seoul 首爾
사랑 sarang 愛
친구 chingu 朋友
라면 ramyeon 泡麵
한국어 hangugeo 韓語

注意 한국어 這個詞：因為 어 是以不發音的 ㅇ 開頭，국 的收尾音 ㄱ 會滑到下一個音節，所以要唸成「han-gu-geo」。只要收尾音碰上母音，韓語就會這樣連音，讓說話聽起來更流暢。

第一個小時的學習小撇步

  • 先學母音。 只有十個，而且是每個方塊的骨幹。
  • 讀真正的單字，而不只是字母。 店家招牌、地鐵站名和K-pop歌名都是絕佳的練習素材。
  • 每個方塊都親手寫寫看。 筆順大致是由上到下、由左到右。
  • 別依賴羅馬拼音太久。 它就像拐杖，可能會掩蓋真正的發音，特別是 ㅓ 和 ㅡ。
