-(으)ㄴ/는/(으)ㄹ 것 같다

好像、看起來；我覺得（推測或委婉意見）

第 2 級 · TOPIK I · 初級

用法

表示根據所見所知的推測，或讓自己的意見聽起來委婉。冠形詞形表示時間：動詞 -(으)ㄴ（過去）、-는（現在）、-(으)ㄹ（未來／推測）；形容詞 -(으)ㄴ（現在）、-(으)ㄹ（推測）。

活用方式

오다→ 온 것 같아요
오다→ 오는 것 같아요
오다→ 올 것 같아요
바쁘다→ 바쁜 것 같아요

形容詞絕不接 -는：✗ 바쁘는 것 같아요 → 바쁜 것 같아요。ㅂ 不規則：춥다 → 추울 것 같아요。

例句

  • 하늘이 어두워요. 곧 비가 올 것 같아요.

    天色很暗，好像快要下雨了。

  • 선생님이 오늘 좀 피곤하신 것 같아요.

    老師今天好像有點累。

與相似句型比較

-나 보다 是根據證據推論，不用於自己的經驗或意見；-(으)ㄴ/는 모양이다 是根據跡象做較客觀的推論；-(으)ㄴ/는 듯하다 是書面說法。
