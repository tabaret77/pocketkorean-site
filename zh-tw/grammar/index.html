  • -(으)ㄹ未來／尚未發生的冠形詞形：要做的 N、將會做的 N
  • -는 것名詞化：把動詞變成名詞（做…這件事）
  • -기名詞化 -기（用於固定說法、興趣、技能、列舉）
  • -고 싶어 하다（別人）想要…——第三人稱的願望

  • -(으)면서一邊…一邊…：同時做兩個動作
  • -는 동안在…期間（一段時間）；N 동안 = N 期間、N 之久
  • -고 나서（做完）…之後
  • -(으)ㄹ까 하다在考慮要做…（未定的計畫）
  • -기로 하다決定要…；（和某人）約好要…
  • -(으)ㄹ 줄 알다/모르다會 / 不會（學來的技能）
  • -아/어 있다處於某種狀態（動作的結果持續）
  • -군요原來如此（對剛得知的事的反應）
  • -게…地（形容詞變副詞）；讓…能（目的）
  • -게 되다變得會…、最後…、結果…
  • -아/어지다變得（形容詞的狀態變化）；被…（被動）
  • -(으)면 좋겠다希望…、要是…就好了
  • -는 게 좋겠다最好…、還是…比較好（委婉建議）
  • -(으)ㄴ 지自從…以來：動作發生後過了多久
  • -는 중이다正在…當中；N 중 = N 中
  • -아/어 버리다做完、…掉了；結果還是…（如釋重負或遺憾）
  • -기 시작하다開始…
  • -(으)ㄴ/는데요委婉語尾：暗示、猶豫、交代背景、禮貌地表示不同意
  • -나요/-(으)ㄴ가요委婉、禮貌的疑問語尾
  • -지 말고不要做 A，改做 B
  • -아/어 보이다看起來（形容詞，從外表判斷）
  • -(으)려고為了…、打算…
  • -(으)려면如果想要…、要…的話（把目標當條件）
  • -(으)면 되다只要…就可以了
  • -아/어도即使、就算
  • N(이)라서因為是 N（以名詞表示原因）
  • -거든요因為…嘛（提供聽者不知道的理由）
  • -다가正在做…（然後）：動作中斷或轉換
  • -기 위해(서)為了…；N을/를 위해(서) = 為了 N
  • -아/어야겠다我得…、我最好…（說話者的決定或決心）
  • -아/어하다把感受形容詞變成動詞（某人表現出那種感受）
  • -지 않아도 되다不必、不用
  • -(으)ㄴ/는지/(으)ㄹ지是否；什麼／哪裡／什麼時候…（間接疑問）
  • -기(가) 쉽다/어렵다容易 / 難以做…（也可：方便、適合做…）
  • -아/어 놓다/두다事先做好（以備後用）；讓某物保持那個狀態
  • -는 게 어때요?…怎麼樣？（禮貌的提議）
  • N이/가 아니라不是 N 而是（另一個 N）；不是 A 而是 B
  • N(이)라고 하다叫做 N；說「…」（直接引用）
  • -ㄴ/는다고 하다間接引用：（某人）說…
  • -냐고 하다間接引用：（某人）問是否／什麼…
  • -(으)라고 하다間接引用：（某人）叫（某人）做…
  • -자고 하다間接引用：（某人）提議一起做…（「…吧」）
  • -잖아요…不是嘛（提醒對方已知的事）
  • -든지或是…或是…；不管…還是…；任何（隨時、什麼都）
  • -(으)ㄴ/는 대신(에)代替…；作為…的交換；但相對地…
  • -기도 하다也會…、有時會…；既…又…（-기도 하고 -기도 하다）
  • -는 길에在去／來（某處）的路上
  • -기 바라다希望…、祝…（正式）

  • -(으)ㄹ수록越…越…
  • -자마자一…就…

  • -(으)ㄹ 뿐만 아니라不但…而且…
  • -(으)ㄹ지도 모르다可能、說不定（不確定的可能性）
  • -나 보다好像…、看來…（根據所見推論）
  • -아/어 오다/가다一直…到現在（오다）／繼續…下去（가다）
  • -게 하다讓／叫某人做；使某物變得…
  • -이/히/리/기-被動詞：被看見、被抓、被打開、被抱
  • -이/히/리/기/우/구/추-使動詞：餵、給…穿、弄哭、叫醒（某人）
  • -느라(고)因為（忙著）做…
  • -아/어야只有…才…（必要條件）
  • -(으)ㄴ/는 척하다假裝（做／是）
  • -(으)ㄹ 뻔하다差點、險些（但最後沒發生）
  • -(으)ㄴ/는 덕분에多虧…、托…的福（好的結果）
  • -는 데在做…上、為了做…——搭配時間、費用、用途、幫助

  • -(으)나但是、然而（書面）
