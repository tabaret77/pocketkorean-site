單字與會話

每日單字、韓劇台詞、日常用語，以及韓國人現在常用的流行語。

全部每日單字韓劇台詞日常用語流行語與新詞敬語 vs 半語
韓劇台詞

韓劇裡的道別台詞：從 잘 가 到 잘 지내

公車站、機場和最後一集：學會韓劇角色道別時常用的九句台詞，從日常的 잘 가 到最後的 잘 지내，以及哪些可以在現實生活中使用。

本篇韓文句子: 잘 지내 = 保重／好好過日子
日常用語

韓語的稱讚：怎麼稱讚別人，又該怎麼回應

從 잘했어요、멋있어요 到 부러워요，學會韓國人每天都在用的稱讚，以及有禮貌的回應方式：아니에요、감사합니다 和 과찬이세요。

本篇韓文句子: 과찬이세요 = 您過獎了（字面意思：那是過度的稱讚）
流行語與新詞

칼퇴、회식、불금：每個上班族都懂的韓國職場流行語

準時下班、部門聚餐、加班和那種星期五的感覺：學會韓國上班族在用的職場詞彙和流行語，從 칼퇴、월급루팡 到 넵 和 퇴근각。

本篇韓文句子: 칼퇴 = 準時下班
每日單字

눈치：韓國人察言觀色的藝術

눈치 是不用別人說出口，就能默默感覺到對方心情的能力。學會 눈치가 빠르다、눈치가 없다、눈치 보다、눈치채다 和 눈치껏，並搭配職場、學校和家裡的例句。

本篇韓文句子: 눈치 = 察覺氣氛、察言觀色
敬語 vs 半語

從 해 줘 到 해 주실 수 있으세요?：韓語請求的五個層級

韓語請人幫忙有一整套階梯，從簡短的 해 줘 到非常委婉的 해 주실 수 있으세요?。學會這五個階段、緩和語氣的 혹시、좀 和 죄송한데，以及各自適合的場合。

本篇韓文句子: 해 주시겠어요? = 可以請您（幫我）做嗎？
每日單字

가을 타다：用韓語說「秋天到了，心情有點憂鬱」

落葉紛飛、天色早早變暗的時候，韓國人會說自己 가을 타다——字面上是「搭上秋天」。學會它的意思、用法，還有它的親戚 추위를 타다 和 더위를 타다。

本篇韓文句子: 가을 타다 = 秋天時感到低落或惆悵
韓劇台詞

韓劇道歉台詞：從 미안해 到 우리 화해하자

每對韓劇情侶都會吵架，而每次吵架最後都以道歉收場。學會九句道歉、請求原諒和和好的台詞，以及每一句背後的文法。

本篇韓文句子: 화 풀어 = 別再生氣了／消消氣
敬語 vs 半語

씨、님、선배、언니：韓語怎麼稱呼別人

韓語會避免用「你」，而是用名字和稱謂。學會什麼時候該說 민지 씨、팀장님、선배 或 언니，以及哪些稱呼可能會不小心聽起來很沒禮貌。

本篇韓文句子: 씨 = 先生／小姐（接在名字後面的禮貌稱呼）
日常用語

韓語講電話用語：從 여보세요 到 들어가세요

用新學的語言講電話很難：沒有手勢，也看不到對方的嘴型。學會怎麼用韓語接電話、表明身分、請對方再說一次、留言，以及有禮貌地掛電話。

本篇韓文句子: 여보세요 = 喂？（講電話時）
流行語與新詞

「너 T야?」：韓國人怎麼用 MBTI 聊天

在韓國，「你的 MBTI 是什麼？」是閒聊話題，而 너 T야? 則是開玩笑的吐槽。學會你會聽到的 MBTI 用語和迷因，以及什麼時候用才恰當。

本篇韓文句子: 너 T야? = 你是 T 嗎？（意思是：你怎麼這麼沒同理心？）
每日單字

화이팅：韓國人在重要日子前怎麼幫人加油

11月的 수능 大考即將到來，到處都聽得到 화이팅。學會它的意思、拼法，以及用韓語說「祝你好運」更溫暖的說法。

本篇韓文句子: 화이팅 = 加油！／你做得到！
韓劇台詞

韓劇告白台詞：從 좋아해 到 우리 사귈래?

幾乎每部韓劇愛情故事都會出現的八句浪漫台詞，從第一句 좋아해 到 오늘부터 1일，附上每一句背後的文法。

本篇韓文句子: 우리 사귈래? = 要不要跟我交往？
敬語 vs 半語

먹다、드시다、잡수시다：為了表示尊敬而改變的韓語單字

談到長輩時，有些韓語動詞和名詞會整個換掉：먹다 變成 드시다，자다 變成 주무시다，집 變成 댁。學會這些重要的對照組。

本篇韓文句子: 드시다 = 吃、喝（尊敬語）
流行語與新詞

ㄱㅅ、ㅊㅋ、ㄹㅇ：用子音打成的韓語聊天縮寫

韓國人傳訊息會只打字首子音：ㄱㅅ 是謝謝，ㅈㅅ 是抱歉，ㅇㅈ 是同意。學會 초성 縮寫怎麼運作，以及可以傳給誰。

本篇韓文句子: 초성 = （音節的）初聲、字首子音
日常用語

用韓語跟朋友約見面：從 시간 돼? 到 그때 봐

問朋友有沒有空、提議要做什麼、約好時間地點，還有委婉地拒絕：跟朋友見面需要的日常韓語。

本篇韓文句子: 시간 돼? = 你有空嗎？
韓劇台詞

每部韓劇都聽得到的10句台詞

從 밥 먹었어? 到 정신 차려，學會幾乎每部韓劇都會出現的十句日常台詞，附上語感和禮貌程度說明。

本篇韓文句子: 밥 먹었어? = 吃飯了沒？（半語）
每日單字

괜찮아요：我沒事、沒關係、不用了，還有不錯喔

一個詞，四種用法。學會韓國人如何用 괜찮아요 表示自己沒事、原諒對方、禮貌婉拒，以及含蓄地稱讚。

本篇韓文句子: 괜찮아요 = 沒關係／我沒事
敬語 vs 半語

존댓말 vs 반말：什麼時候換、怎麼換

了解韓國人什麼時候用敬語、什麼時候不用，怎麼提議改說半語，以及隨之而來的小小用詞變化。

本篇韓文句子: 말 놓을까요? = 我們要不要說半語？
流行語與新詞

2026年網路上常見的韓語流行語

ㅋㅋ、헐、갓생、킹받다 等等：留言和聊天室裡會遇到的韓國網路流行語，附上意思和每個詞的失禮程度。

本篇韓文句子: 신조어 = 新詞、流行語
日常用語

在韓國咖啡廳點餐：真的用得到的句子

從 아이스 아메리카노 한 잔 주세요 到外帶、加濃縮，還有店員遞給你的取餐呼叫器，有自信地用韓語點咖啡。

本篇韓文句子: 주세요 = 請給我
