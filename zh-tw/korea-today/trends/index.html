流行趨勢

탐조：為什麼韓國年輕人開始迷上賞鳥

賞鳥一度被視為拿著大砲相機的中年大叔的嗜好，如今正成為韓國千禧世代和 Z 世代的潮流休閒——常常只需要一支手機，在公寓社區或都市公園裡就能進行。

本篇韓文句子: 탐조 = 賞鳥
流行趨勢

檸檬、薄荷、紫色：韓國冬季羽絨外套變得五彩繽紛

多年來黑色羽絨外套一直稱霸韓國的冬天，但這一季消費者搜尋的是紫色、檸檬黃和薄荷綠。來看看數據怎麼說，以及買 패딩 時需要的韓語。

本篇韓文句子: 패딩 = 羽絨外套、鋪棉外套
流行趨勢

生魚片野餐：為什麼首爾年輕人要帶生魚片去漢江

炸雞在漢江邊出現了對手。韓國年輕人在鷺梁津市場買生魚片，帶到河邊野餐，這股潮流叫做 hoe-cnic（회크닉）。

本篇韓文句子: 회크닉 = 生魚片野餐（회 + picnic）
流行趨勢

「現百風」：韓國年輕人瘋迷的百貨公司穿搭

「現百風」（Hyunbaek core）這個新的穿搭標籤正在韓國社群媒體上流行。一起來看看它的意思，還有背後的韓語流行語。

本篇韓文句子: 현백 코어 = 現代百貨風（不費力的有錢感穿搭）
