-ㄴ/는다

plain style (해라체): writing, diaries, news; to close juniors

Level 3 · TOPIK II · intermediate

How to use it

Present: verb stem + -ㄴ다 (no batchim) / -는다 (batchim); adjective + -다; N + (이)다. Past -았/었다, future -겠다 / -(으)ㄹ 것이다. Question -니? / -(느)냐?, command -아/어라, suggestion -자.

Forming it

가다→ 간다
먹다→ 먹는다
좋다→ 좋다
학생→ 학생이다

Verbs need -ㄴ/는다 in the present: ✗ 나는 밥을 먹다 → 먹는다. Adjectives take only -다: ✗ 좋는다. ㄹ-stems drop ㄹ: 살다 → 산다.

Examples

  • 나는 매일 아침 공원에서 운동을 한다.

    I exercise in the park every morning.

  • 오늘은 바람이 많이 불어서 날씨가 무척 춥다.

    Today the wind is blowing a lot, so it is very cold.

Compared with similar patterns

-아/어 is casual spoken speech. -ㅂ/습니다 is formal and polite to the listener; -ㄴ/는다 shows no politeness, so it is neutral in writing but casual in speech.
