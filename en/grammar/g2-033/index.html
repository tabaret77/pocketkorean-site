N(이)라서

because it is N (reason with a noun)

Level 2 · TOPIK I · beginner

How to use it

The copula 이다 + -아/어서 in its common spoken form, giving a noun as the reason. After a vowel -라서 (휴가라서), after a consonant -이라서 (학생이라서).

Forming it

학생→ 학생이라서
주말→ 주말이라서
휴가→ 휴가라서
처음→ 처음이라서

Like -아/어서, not followed by commands or 'let's': ✗ 주말이라서 같이 가요 → 주말이니까 같이 가요. 이어서/여서 means the same (학생이어서).

Examples

  • 오늘은 주말이라서 사람이 많아요.

    It's the weekend today, so there are a lot of people.

  • 한국은 처음이라서 아직 잘 몰라요.

    It's my first time in Korea, so I don't know much yet.

Compared with similar patterns

-아/어서 is the same pattern for verbs and adjectives; N이기 때문에 is more formal; N이/가 아니라 means 'not N but …' (and N이/가 아니라서 'because it isn't N').
