-기 시작하다

begin to, start doing

Level 2, TOPIK I · beginner

How to use it

Marks the start of an action or state. The tense goes on 시작하다.

Forming it

오다→ 오기 시작했어요
배우다→ 배우기 시작했어요
먹다→ 먹기 시작했어요

✗ 비가 왔기 시작했어요 → 비가 오기 시작했어요.

Examples

  • 밖에 나가자마자 갑자기 비가 오기 시작했어요.

    As soon as I went out, it suddenly started to rain.

  • 작년부터 피아노를 배우기 시작했어요.

    I started learning piano last year.

Compared with similar patterns

-게 되다 shows a change brought about by circumstances; -아/어지다 shows a gradual change of state (with adjectives), not the starting point of an action.

Related patterns

  • -게 되다 come to (do), end up (doing), it turned out that
  • -아/어지다 become (change of state with adjectives); be done (passive)
