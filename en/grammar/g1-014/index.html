-(으)ㄹ 거예요

will, be going to (plan); will probably (guess)

Level 1 · TOPIK I · beginner

How to use it

1) Future plans, with I/you as subject: 'will, be going to'. 2) A guess about someone else or a situation: 'will probably'.

Forming it

가다→ 갈 거예요
먹다→ 먹을 거예요
만들다→ 만들 거예요
듣다→ 들을 거예요

ㄹ-stems add only -ㄹ: 만들다 → 만들 거예요 (✗ 만들을 거예요). For a guess about the past use -았/었을 거예요 (벌써 도착했을 거예요).

Examples

  • 내일은 집에서 쉴 거예요.

    I'm going to rest at home tomorrow.

  • 주말이라서 길이 많이 막힐 거예요.

    It's the weekend, so the roads will probably be busy.

Compared with similar patterns

-(으)ㄹ게요 is a promise or decision made in response to the listener; -겠- shows firmer or more formal intention; -(으)ㄹ 것 같다 is a softer guess based on what you see or feel.
