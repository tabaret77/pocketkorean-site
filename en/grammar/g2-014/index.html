-아/어 있다

be in a state (the result of an action continues)

Level 2 · TOPIK I · beginner

How to use it

Shows that the result of a completed change continues: 앉아 있다 'be seated', 열려 있다 'be open'. Used with intransitive and passive verbs (no object).

Forming it

앉다→ 앉아 있어요
서다→ 서 있어요
열리다→ 열려 있어요
붙다→ 붙어 있어요

Not with transitive verbs that take an object: ✗ 문을 열어 있어요 → 문이 열려 있어요 / 문을 열어 놓았어요. For wearing clothes use -고 있다: 코트를 입고 있어요.

Examples

  • 문이 열려 있어서 그냥 들어갔어요.

    The door was open, so I just went in.

  • 할머니께서 의자에 앉아 계세요.

    Grandmother is sitting in the chair.

Compared with similar patterns

-고 있다 is an action in progress (앉고 있다 = is in the act of sitting down); -아/어 놓다/두다 is a transitive action done on purpose with the result kept.
