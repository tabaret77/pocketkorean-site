-도록

so that, in order that; to the point that; until

Level 3 · TOPIK II · intermediate

How to use it

Purpose: clause 2 is done so that clause 1 happens (often with a different subject or with 않도록). Degree/time: 밤새도록 (all night), 목이 아프도록 (until my throat hurt).

Forming it

듣다→ 듣도록
늦다→ 늦지 않도록
밤새다→ 밤새도록
알다→ 알도록

No tense marker before -도록: ✗ 들렸도록.

Examples

  • 감기에 걸리지 않도록 따뜻하게 입으세요.

    Dress warmly so that you don't catch a cold.

  • 친구와 밤새도록 이야기를 했어요.

    I talked with my friend all night long.

Compared with similar patterns

-게 is very close but more casual. -(으)려고 shows the subject's own intention and cannot be followed by a command; -도록 can. -도록 하다 is a sentence-final expression.

Related patterns

  • -게 -ly (adverb from an adjective); so that (purpose)
  • -(으)려고 in order to, with the intention of
  • -도록 하다 make sure to …; (I) will see to it; have someone do
