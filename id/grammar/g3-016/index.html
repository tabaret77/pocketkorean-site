Pola tata bahasa Korea › Level 3

-기는요

Ah, tidak juga; apa maksudnya … (penyangkalan rendah hati atau ringan)

Level 3 · TOPIK II · menengah

Cara pakai

Mengulang kata lawan bicara untuk menyangkal pujian atau ucapan terima kasih dengan rendah hati, atau untuk tidak setuju secara ringan. Bentuk santai: -기는 / -긴.

Cara membentuk

잘하다→ 잘하기는요
예쁘다→ 예쁘기는요
고맙다→ 고맙기는요

Biasanya dilekatkan pada batang kata saja meskipun pujiannya dalam bentuk lampau (잘했어요 → 잘하기는요). Jika dipakai untuk tidak setuju, bisa terdengar ketus.

Contoh

  • 가: 한국어 정말 잘하시네요. 나: 잘하기는요. 아직 멀었어요.

    A: Bahasa Korea kamu bagus sekali. B: Ah, tidak juga. Saya masih harus banyak belajar.

  • 고맙기는요. 친구끼리 당연히 도와야죠.

    Tidak perlu berterima kasih. Teman memang sudah seharusnya saling membantu.

Dibandingkan pola yang mirip

-(으)ㄴ/는걸요 membantah dengan ringan dengan menyatakan fakta sebaliknya; -기는요 langsung menyangkal apa yang baru saja dikatakan.
