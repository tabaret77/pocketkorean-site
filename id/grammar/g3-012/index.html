-았/었다가

sudah … lalu (dibatalkan / terjadi hal lain)

Level 3, TOPIK II · menengah

Cara pakai

Tindakan pertama selesai, lalu diikuti tindakan sebaliknya atau sesuatu terjadi sebagai akibatnya (biasanya: pergi ke suatu tempat lalu…). Subjeknya sama di kedua klausa.

Cara membentuk

가다→ 갔다가
입다→ 입었다가
켜다→ 켰다가
사다→ 샀다가

Sering berupa pasangan berlawanan: 입었다가 벗다, 켰다가 끄다, 앉았다가 일어나다.

Contoh

  • 옷을 샀다가 마음에 안 들어서 바꿨어요.

    Saya sudah membeli baju itu, tapi tidak suka, jadi saya tukar.

  • 도서관에 갔다가 문이 닫혀서 그냥 왔어요.

    Saya pergi ke perpustakaan, tapi tutup, jadi saya langsung pulang.

Dibandingkan pola yang mirip

-다가 beralih ketika tindakan pertama masih berlangsung; -았/었다가 beralih setelah tindakan itu selesai. -(으)려다가 berarti seseorang tadinya hendak melakukan sesuatu tetapi tidak jadi.

Latih dengan audio dan kuis

Pocket Korean punya rekaman penutur asli untuk setiap contoh, pengulangan berkala, dan simulasi TOPIK.

Mulai gratis di browser

Pola terkait

  • -다가 sedang … lalu: tindakan terputus atau beralih
  • -(으)려다(가) tadinya mau … tapi (ganti rencana / terjadi sesuatu)
